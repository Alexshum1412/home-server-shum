# CLAUDE.md

Общие правила проекта — в [AGENTS.md](AGENTS.md) (прочитай его первым). Здесь — только то, что специфично для Claude Code.

- **Дизайн UI**: токены и общий слой оформления — `web/src/styles/tokens.css` и `premium.css`; не создавай второй дизайн-язык. При изменениях интерфейса сверяйся со skills `frontend-design` и `ui-ux-pro-max`, затем проверь в браузере на телефоне и ПК.
- **Браузерные проверки**: `npm.cmd run test:e2e`; браузер — установленный Chrome, ничего не скачивать.
- **Оболочка**: Windows PowerShell 5.1; `.ps1`-скрипты с кириллицей сохранять в UTF-8 **с BOM**; `.cmd` — только ASCII.
- **Отчёты**: пиши пользователю по-русски; помечай статусы «реализовано / проверено автоматически / проверено вручную / требует настройки / не работает»; не утверждай, что что-то работает, если проверка не запускалась.
