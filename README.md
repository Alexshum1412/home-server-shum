# Семейный сервер

Домашний портал для семьи: кино, фото, файлы, дела, чат со звонками, помощница Оливия, дайджест и офлайн-библиотека. Работает на домашнем компьютере с Windows; данные остаются дома.

Руководство для семьи — [docs/FAMILY_USER_GUIDE.md](docs/FAMILY_USER_GUIDE.md).

## Состав
- `server/` — сервер (Node.js 24, TypeScript, Fastify).
- `web/` — интерфейс (Preact, Vite), устанавливается на телефон как приложение (PWA).
- `shared/` — общие типы между сервером и интерфейсом.
- `scripts/` — запуск, остановка, резервные копии, учётные записи, перенос на другое устройство.
- `tests/`, `server/test/`, `web/src/**/*.test.ts` — автоматические проверки.

## Быстрый старт
```
npm.cmd ci
npm.cmd run build
scripts\start.cmd
```
После запуска портал открывается на `http://127.0.0.1:8070`. Первого администратора создаёт `scripts\user.cmd add <логин> --name "Имя" --role admin`. Настройки задаются в файле `.env` (образец — `.env.example`); секреты и данные семьи в репозиторий не попадают.

## Команды
| Команда | Что делает |
|---|---|
| `npm.cmd run dev` | сервер и интерфейс для разработки |
| `npm.cmd run check` | линтер, типы, тесты, сборка, браузерные тесты |
| `scripts\start.cmd`, `stop.cmd`, `restart.cmd`, `status.cmd` | управление сервером |
| `scripts\backup.cmd` | резервная копия |
| `scripts\move-server-pack.cmd`, `scripts\move-server-setup.cmd` | перенос сервера на другое устройство |

## Автозапуск после перезагрузки
Программы сервера запускаются сами при включении компьютера (задача планировщика, `scripts\autostart.cmd`). Чтобы Windows ещё и входила в учётную запись без участия человека, используйте утилиту Autologon (Microsoft Sysinternals, уже скачана): `scripts\autologon.cmd` откроет её окно, пароль вводите вы сами — проект его не видит.

## Перенос на другое устройство
1. На старом сервере: `scripts\move-server-pack.cmd` — соберёт один архив с настройками и секретами (храните его как пароль).
2. На новом устройстве (PowerShell от администратора): `scripts\move-server-setup.cmd -Package <архив>` — поставит программы, соберёт портал, вернёт данные и включит автозапуск. Опция `-DryRun` только покажет шаги.
3. Большие папки (фильмы, фото, офлайн-библиотека) копируются отдельно.
