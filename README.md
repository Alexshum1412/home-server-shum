# Семейный сервер — портал

Один адрес и одна иконка для всей семьи: кинотеатр, фото, файлы, загрузки, печать и состояние домашнего компьютера. Портал работает на этом ПК (Windows 10), открывается дома и из других стран через Tailscale и честно показывает, что работает, что ещё не настроено и что сломано.

> Это первый рабочий этап (MVP). Сами сервисы (Jellyfin, Immich, файлы, загрузки) ещё не установлены — портал показывает их как «Не настроено». Что готово и что дальше — в [docs/roadmap.md](docs/roadmap.md).

## Что уже умеет

- Вход по имени и паролю; роли «семья» и «администратор» (права проверяет сервер).
- Главная: приветствие, большой «Кинотеатр», карточки сервисов, состояние дома, важные предупреждения простым языком.
- Реальные данные этого ПК: процессор, память, место на диске, состояние физических дисков (включая неисправный второй диск), принтер HP по данным Windows, Tailscale, статус резервного копирования. Нет данных — так и написано, нули не выдумываются.
- Администрирование: журнал входов и действий, список пользователей, диагностический отчёт без секретов, ручная проверка сервисов.
- Телефон и компьютер: адаптивный интерфейс (375–1440 px), тёмная и светлая тема, установка на домашний экран (PWA), без внешних шрифтов и CDN.
- Демо-режим с явной пометкой «Демо» — чтобы посмотреть интерфейс с «работающими» сервисами.

## Быстрый старт на этом компьютере

Node.js 24 и Git уже установлены (в `%LOCALAPPDATA%\Programs`). Откройте папку проекта `C:\Users\PC\Desktop\THE DASHBOARD` и выполните в **командной строке** или PowerShell:

```bat
npm.cmd ci
npm.cmd run build
scripts\user.cmd add alex --name "Алекс" --role admin
scripts\start.cmd
```

Откройте в браузере на этом ПК: **http://127.0.0.1:8070** и войдите.

> В PowerShell пишите именно `npm.cmd`, а не `npm`: политика выполнения Windows по умолчанию блокирует `npm.ps1`. Менять её не нужно.

### Семья и телефоны

1. Добавьте родственников (пароль вводится дважды и не отображается, минимум 10 символов):
   ```bat
   scripts\user.cmd add mama --name "Мама" --role family
   ```
2. Частный HTTPS-адрес внутри вашей сети Tailscale **уже включён** (16.10.2026): **https://server-home.tail89d77e.ts.net** — работает только на устройствах, где включён Tailscale вашей сети; из интернета он недоступен. Выключить/включить снова: `scripts\serve-tailnet.cmd -Off` / `scripts\serve-tailnet.cmd`.
3. На телефоне: открыть адрес → iPhone: Safari → «Поделиться» → «На экран Домой»; Android: Chrome → меню → «Добавить на главный экран». Подробно — на странице портала «Подключение».

## Ежедневные команды

| Что | Команда |
|---|---|
| Запустить в фоне | `scripts\start.cmd` |
| Остановить | `scripts\stop.cmd` |
| Состояние, адреса, Tailscale Serve | `scripts\status.cmd` |
| Автозапуск при входе в Windows (вкл./выкл.) | `scripts\autostart.cmd` / `scripts\autostart.cmd -Off` |
| Частный HTTPS (вкл./выкл.) | `scripts\serve-tailnet.cmd` / `scripts\serve-tailnet.cmd -Off` |
| Пользователи | `scripts\user.cmd list` · `add` · `passwd` · `role` · `remove … --yes` |

`.cmd`-файлы можно запускать двойным щелчком. Логи: `%LOCALAPPDATA%\FamilyDashboard\logs`.

## Проверка (для разработчика)

Всё по очереди одной командой (линтер Biome, типы TypeScript, тесты Vitest, сборка интерфейса, e2e-тесты Playwright в установленном Google Chrome):

```bat
npm.cmd run check
```

По отдельности: `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run test:e2e`.
Режим разработки: `npm.cmd run dev` (API на :8070 с автоперезапуском, интерфейс на http://127.0.0.1:5173).

## Настройки

Необязательный файл `.env` (образец — [.env.example](.env.example)): порт, каталог данных, демо-режим, тома для контроля места, имя принтера, адреса. Секреты не нужны. По умолчанию сервер слушает только `127.0.0.1:8070`.

Список сервисов — `%LOCALAPPDATA%\FamilyDashboard\services.json` (создаётся при первом запуске). Чтобы подключить, например, Jellyfin, укажите у записи `media` адрес `openUrl` (то, что откроет семья) и `healthUrl` (проверка, например `http://127.0.0.1:8096/health`).

## Установка на новом ПК

1. Node.js 24 LTS: официальный ZIP `node-v24.x-win-x64.zip` с nodejs.org (сверить SHA-256 с `SHASUMS256.txt`), распаковать в `%LOCALAPPDATA%\Programs\nodejs`, добавить папку в PATH пользователя. Или официальный установщик MSI.
2. Git for Windows (по желанию; нужен для истории изменений).
3. Скопировать папку проекта, затем «Быстрый старт».

Подробно, с проверкой хэшей — [docs/tooling.md](docs/tooling.md).

[docs/runbooks/troubleshooting.md](docs/runbooks/troubleshooting.md). Частые случаи: порт занят, интерфейс не собран, Tailscale не подключён после перезагрузки (откройте приложение Tailscale и войдите), забыт пароль (`scripts\user.cmd passwd <логин>`).

## Важно знать

- **Windows 10 на этом ПК не получала обновлений безопасности 12 месяцев.** Рекомендуется включить обновления / программу ESU (см. `docs/environment-audit.md`). Поэтому портал не публикуется в интернет.
- **Второй диск неисправен или заблокирован** (`ST_M13FQBL`, 3,9 ГБ). Не инициализируйте и не форматируйте его — см. `docs/runbooks/second-disk.md`.
- **Резервных копий пока нет** — портал так и пишет. Нужен второй носитель: `docs/runbooks/backup-restore.md`.
- Удалённый доступ работает, только когда ПК включён, в Windows выполнен вход (Tailscale на Windows работает в сессии пользователя) и дома есть интернет.
