# Семейный сервер — портал

Один адрес и одна иконка для всей семьи: кинотеатр, фото, файлы, загрузки, печать и состояние домашнего компьютера. Портал работает на этом ПК (Windows 10), открывается дома и из других стран через Tailscale и честно показывает, что работает, что ещё не настроено и что сломано.

> Что уже работает и что ещё нет — в [docs/EXECUTION_STATUS.md](docs/EXECUTION_STATUS.md). Для семьи — [docs/FAMILY_USER_GUIDE.md](docs/FAMILY_USER_GUIDE.md) с картинками. Что **ещё требует вас** (установка торрент-клиента и модели, туннель, проверка звонка на двух устройствах) — [docs/owner-actions.md](docs/owner-actions.md); пока это не сделано, возможность не считается работающей. Если что-то сломалось или не настроено, портал так и пишет.

## Что уже умеет

- Вход по имени и паролю; роли «семья» и «администратор» (права проверяет сервер); временный пароль для первого входа и смена своего пароля в «Мой профиль».
- Автозапуск при включении ПК и перезапуск после сбоя или зависания (супервизор + задача планировщика «FamilyServer»).
- Главная: приветствие, большой «Кинотеатр», карточки сервисов, состояние дома, важные предупреждения простым языком.
- Реальные данные этого ПК: процессор, память, место на диске, состояние физических дисков (включая неисправный второй диск), принтер HP по данным Windows, Tailscale, статус резервного копирования. Нет данных — так и написано, нули не выдумываются.
- Кинотеатр **Jellyfin** (https://server-home.tail89d77e.ts.net:8443 в tailnet): фильмы, сериалы, мультфильмы, домашнее видео, музыка; прямое воспроизведение и перекодирование на видеокарте — [docs/runbooks/jellyfin.md](docs/runbooks/jellyfin.md).
- **Файлы и фото** прямо в портале: у каждого личное пространство, у семьи — общее. Загрузка с телефона (до 20 ГБ на файл), фото и видео по месяцам, корзина — [ADR-0007](docs/decisions/0007-files-and-photos.md).
- **Загрузки** по ссылке (право `downloads`): ссылка проверяется до старта, загрузка начинается только после подтверждения. Пауза, продолжение, отмена, прогресс; готовый файл — в «Файлы → Личное → Загрузки» — [ADR-0006](docs/decisions/0006-downloads.md).
- **Календарь и заметки** для семьи: общие и личные события с повторами, «сегодня и завтра» на главной, файл `.ics` для телефона; заметки — обычные текстовые файлы в «Файлах».
- **Аудиокниги** в Jellyfin (библиотека «Аудиокниги») и запасной плеер в портале, который играет файлы медиатеки, даже когда Jellyfin не работает.
- **Люди из портала:** администратор добавляет человека, выдаёт новый временный пароль, меняет права, удаляет пользователя. Запасной путь — `scripts\user.cmd`.
- **Семейный чат и звонки** (с 18.10.2026): личные и групповые разговоры, фото и файлы, прочитано/доставлено; голос и видео до 4 человек (WebRTC); переписку видят только участники, даже администратор — [ADR-0012](docs/decisions/0012-family-chat-and-calls.md), [runbook](docs/runbooks/chat-and-calls.md). Уведомления в портале и Web Push (на iPhone — только для портала «На экране Домой»).
- **Каталог «Кинотеатра»**: афиши, описания, жанры, поиск, «Продолжить просмотр» у каждого своё, запасной просмотр без Jellyfin.
- **Торренты** в «Загрузках» через aria2 на loopback (очередь, пауза, повтор, обновление Jellyfin) — [ADR-0014](docs/decisions/0014-torrent-queue.md); клиент нужно установить: [runbook](docs/runbooks/torrents.md).
- **«Оливия» для всей семьи**: поиск фильмов, фото и файлов, место на диске, загрузки, календарь, справка; необязательная **локальная** модель выбирает инструмент, ответы собираются из фактов, облака нет — [ADR-0011](docs/decisions/0011-olivia-local-model.md), [runbook](docs/runbooks/local-ai.md).
- **Дополнительный защищённый HTTPS-адрес** (туннель) только для обычных функций; админка, управление, печать, запуск загрузок и вход администратора через него закрыты — [ADR-0013](docs/decisions/0013-remote-access-public-https.md), [runbook](docs/runbooks/public-https.md). Не настроен, пока вы не заведёте туннель.
- **Состояние оборудования** для администратора: ядра процессора, видеокарта, сеть, счётчики дисков, история за сутки, оповещения о проблемах.
- **Запасные способы** для всех важных функций: [docs/feature-fallback-matrix.md](docs/feature-fallback-matrix.md); что осталось сделать владельцу — [docs/owner-actions.md](docs/owner-actions.md).
- **Печать** PDF и JPG на домашний принтер HP из любого места (право `print`). Принтер сначала проверяет задание, печать идёт только после подтверждения, статус виден до «Напечатано» — [docs/runbooks/printing.md](docs/runbooks/printing.md).
- **«Оливия»** — подсказки администратору по правилам, без ИИ: что сломано и одна безопасная кнопка исправления с подтверждением — [ADR-0008](docs/decisions/0008-olivia-without-ai.md).
- Резервное копирование: каждый день в 03:30 — копия данных портала, семейных файлов и фото, настроек Jellyfin и кода на основной диск и на флешку «reserve», с проверкой по контрольным суммам; результат виден на дашборде.
- Администрирование: журнал входов и действий, список пользователей, диагностический отчёт без секретов, ручная проверка сервисов.
- Телефон и компьютер: адаптивный интерфейс (375–1440 px), тёмная и светлая тема, установка на домашний экран (PWA), без внешних шрифтов и CDN.
- Демо-режим с явной пометкой «Демо» — чтобы посмотреть интерфейс с «работающими» сервисами.

## Быстрый старт на этом компьютере

Всё, что нужно серверу, лежит в одной папке `C:\FamilyServer`: Node.js 24 и Git — в `tools\`, данные портала — в `data\dashboard`, копии — в `backups\` (почему не в AppData — [ADR-0002](docs/decisions/0002-data-storage.md)). Откройте папку проекта `C:\Users\PC\Desktop\THE DASHBOARD` и выполните в **командной строке** или PowerShell:

```bat
npm.cmd ci
scripts\user.cmd add alex --name "Алекс" --role admin --generate-password
scripts\autostart.cmd
scripts\start.cmd
scripts\backup-schedule.cmd
```

Что делают команды:
- `npm.cmd ci` нужен один раз и после обновления кода.
- `--generate-password` выдаёт временный пароль. Он показывается один раз, а при первом входе портал попросит придумать свой.
- `scripts\autostart.cmd` нужно один раз запустить **от имени администратора**: портал будет стартовать при включении ПК и перезапускаться после сбоя.
- `scripts\start.cmd` сам соберёт интерфейс, если он ещё не собран.
- `scripts\backup-schedule.cmd` включает ежедневную копию.

На этом ПК всё это уже сделано 17.10.2026: создан администратор `alex`, включены автозапуск и ежедневная копия. Откройте в браузере на этом ПК **http://127.0.0.1:8070** и войдите.

> В PowerShell пишите именно `npm.cmd`, а не `npm`: политика выполнения Windows по умолчанию блокирует `npm.ps1`. Менять её не нужно.

### Семья и телефоны

1. Добавьте родственников (пароль вводится дважды и не отображается, минимум 10 символов):
   ```bat
   scripts\user.cmd add mama --name "Мама" --role family
   ```
2. Частный HTTPS-адрес внутри вашей сети Tailscale **уже включён** (16.10.2026): **https://server-home.tail89d77e.ts.net** — работает только на устройствах, где включён Tailscale вашей сети; из интернета он недоступен. Выключить/включить снова: `scripts\serve-tailnet.cmd -Off` / `scripts\serve-tailnet.cmd`.
3. На телефоне: открыть адрес → iPhone: Safari → «Поделиться» → «На экран Домой»; Android: Chrome → меню → «Добавить на главный экран». Подробно — на странице портала «Подключение».

## Ежедневные команды

| Что | Команда |
|---|---|
| Запустить в фоне (через супервизор) | `scripts\start.cmd` |
| Остановить (до `start.cmd` или перезагрузки) | `scripts\stop.cmd` |
| Состояние: супервизор, программы, автозапуск, Tailscale Serve | `scripts\status.cmd` |
| Автозапуск при включении ПК (вкл./выкл.) | `scripts\autostart.cmd` (от администратора) / `scripts\autostart.cmd -Off` |
| Частный HTTPS (вкл./выкл.) | `scripts\serve-tailnet.cmd` / `scripts\serve-tailnet.cmd -Off`; для Jellyfin — с `-Jellyfin` |
| Первичная настройка Jellyfin (повторно — безопасно) | `scripts\jellyfin-setup.cmd` |
| Пользователи | `scripts\user.cmd list` · `add` · `passwd` · `role` · `remove … --yes` |
| Права на загрузки и печать | `scripts\user.cmd allow <логин> downloads` или `print`; забрать — `deny` |
| Независимая диагностика без портала | `scripts\doctor.cmd` (`--json` для программ) |
| Управление программами вручную | `scripts\service.cmd status` · `start` · `stop` · `restart <dashboard\|jellyfin>` |
| Файлы и фото с флешки или кабеля / на флешку | `scripts\import.cmd <папка> --user <логин> [--root photos]` · `scripts\export.cmd --user <логин> --to <папка>` |
| Запасной адрес портала дома без интернета | `scripts\lan-mode.cmd status` · `on` · `off` (включает владелец) |
| Резервная копия сейчас / список / проверка | `scripts\backup.cmd` · `list` · `verify` · `test-restore` |
| Ежедневная копия (вкл./выкл.) | `scripts\backup-schedule.cmd` / `scripts\backup-schedule.cmd -Off` |

`.cmd`-файлы можно запускать двойным щелчком. Логи: `C:\FamilyServer\data\dashboard\logs` (журнал копирования — `backup.log`).

## Резервные копии

**Статус: Implemented / Partial.** Задача «FamilyServerBackup» каждый день в 03:30 (или при первой возможности, если ПК был выключен; только пока выполнен вход в Windows) делает копию в два места: `C:\FamilyServer\backups` и флешку с меткой тома `reserve` (`<буква>:\FamilyServerBackups`). В копии — данные портала (без сессий), `.env`, весь Git-код (`repo.bundle`) и настройки Tailscale Serve; каждый файл сверяется по SHA-256; хранится 14 копий в каждом месте. Дашборд показывает итог: «Последняя копия …: основной диск — да, флешка «reserve» — да»; если флешки нет — ошибку.

Ограничения: копия на `C:` — на том же физическом диске; флешка — в том же доме; копии не зашифрованы; копии вне дома пока нет. Восстановление и что делать при ошибках — [docs/runbooks/backup-restore.md](docs/runbooks/backup-restore.md).

**GitHub (третье место):** код проекта автоматически отправляется при каждом копировании в публичный репозиторий https://github.com/Alexshum1412/home-server-shum (только код и документация, без `--force`). Семейные данные в GitHub не отправляются никогда. Если вход в GitHub истёк — выполните `git push` в папке проекта и войдите в открывшемся окне.

## Проверка (для разработчика)

Всё по очереди одной командой (линтер Biome, типы TypeScript, тесты Vitest, сборка интерфейса, e2e-тесты Playwright в установленном Google Chrome):

```bat
npm.cmd run check
```

По отдельности: `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run test:e2e`.
Режим разработки: `npm.cmd run dev` (API на :8070 с автоперезапуском, интерфейс на http://127.0.0.1:5173).

## Настройки

Необязательный файл `.env` (образец — [.env.example](.env.example)): порт, каталог данных, демо-режим, тома для контроля места, имя принтера, адреса. Секреты не нужны. По умолчанию сервер слушает только `127.0.0.1:8070`.

Список сервисов — `C:\FamilyServer\data\dashboard\services.json` (создаётся при первом запуске). Чтобы подключить, например, Jellyfin, укажите у записи `media` адрес `openUrl` (то, что откроет семья) и `healthUrl` (проверка, например `http://127.0.0.1:8096/health`).

## Установка на новом ПК

1. Node.js 24 LTS: официальный ZIP `node-v24.x-win-x64.zip` с nodejs.org (сверить SHA-256 с `SHASUMS256.txt`), распаковать в `C:\FamilyServer\tools\nodejs`, добавить папку в PATH пользователя. Не ставьте в `%LOCALAPPDATA%` из упакованных приложений (например, из Claude Desktop) — Windows спрячет такие файлы от остальных программ.
2. Git for Windows (PortableGit) в `C:\FamilyServer\tools\git`, в PATH — только `cmd\`. Нужен для истории изменений и для копии кода в резервной копии (`GIT_EXE` в `.env`).
3. Скопировать папку проекта; при переносе данных — восстановить их из резервной копии (`docs/runbooks/backup-restore.md`); затем «Быстрый старт».

Подробно, с проверкой хэшей — [docs/tooling.md](docs/tooling.md).

## Важно знать

- **Windows 10 на этом ПК не получала обновлений безопасности 12 месяцев.** Рекомендуется включить обновления / программу ESU (см. `docs/environment-audit.md`). Поэтому портал не публикуется в интернет.
- **Второй диск неисправен или заблокирован** (`ST_M13FQBL`, 3,9 ГБ). Не инициализируйте и не форматируйте его — см. `docs/runbooks/second-disk.md`.
- **Резервные копии есть, но только дома** (основной диск + флешка «reserve»), без шифрования. Флешку держите подключённой и храните бережно; копия вне дома — следующий шаг: `docs/runbooks/backup-restore.md`.
- **Что ещё не установлено и не проверено** (честно): торрент-клиент, локальная модель, туннель, TURN, звонок на двух настоящих устройствах, push на настоящем телефоне — см. [docs/owner-actions.md](docs/owner-actions.md). Файлы для них скачиваются только с вашего согласия, с проверкой размера и SHA-256.
- Удалённый доступ работает, только когда ПК включён, в Windows выполнен вход (Tailscale на Windows работает в сессии пользователя) и дома есть интернет.
