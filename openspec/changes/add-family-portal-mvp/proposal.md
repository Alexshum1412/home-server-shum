# Proposal

## Why

Семье нужен один понятный вход («Семейный сервер») к фильмам, фото, файлам, загрузкам, печати и состоянию домашнего ПК — с телефона из любой страны через Tailscale и из домашней сети. Сейчас в проекте нет кода, а сами сервисы (Jellyfin, Immich и др.) ещё не установлены, поэтому первым шагом нужен рабочий безопасный портал, который **честно** показывает, что работает, что не настроено и что сломано, и к которому потом подключаются сервисы.

## What Changes

- Новый веб-портал (PWA) с адаптивной навигацией: Главная, Кинотеатр, Фото, Файлы, Загрузки, Печать, Состояние системы, Подключение (помощь), Администрирование.
- Вход по имени и паролю, роли `family` и `admin`; права проверяются на сервере.
- Реестр сервисов с периодической проверкой доступности и состояниями `online / degraded / offline / not_configured / disabled / unknown`.
- Реальные системные показатели с временем сбора: CPU, RAM, свободное место, состояние физических дисков, Tailscale, принтер, статус резервного копирования; `null` ≠ `0`; без выдуманных датчиков.
- Предупреждения только из подтверждённых проверок (например, «резервное копирование не настроено», «второй диск определяется некорректно»).
- Журнал аудита и экспорт диагностики без секретов для администратора; CLI для управления пользователями.
- Демо-режим с явной меткой «Демо» для показа интерфейса без установленных сервисов; в обычном режиме выключен.
- Скрипты запуска/остановки на Windows, приватный HTTPS-вход через Tailscale Serve (без Funnel), локальный адрес по умолчанию только `127.0.0.1`.

## Capabilities

### New Capabilities
- `portal-access`: вход, сессии, роли family/admin, защита от перебора и CSRF.
- `service-status`: реестр семейных сервисов и честная проверка их доступности.
- `system-status`: системные показатели домашнего сервера, предупреждения и их происхождение.
- `portal-ui`: страницы, навигация, состояния интерфейса, адаптивность, доступность, PWA.
- `admin-tools`: журнал действий, список пользователей, диагностический отчёт.
- `portal-runtime`: запуск/остановка, сетевые привязки, заголовки безопасности, health endpoint.

### Modified Capabilities
- (нет — первая версия)

## Impact

- Новый код: `server/`, `web/`, `shared/`, `scripts/`, `tests/`; зависимости npm (Fastify, Preact, Vite, Vitest, Playwright, Biome).
- Данные приложения — вне репозитория (`%LOCALAPPDATA%\FamilyDashboard`).
- Сеть: новый порт `127.0.0.1:8070`; Tailscale Serve `https://server-home.tail89d77e.ts.net` → `127.0.0.1:8070`. Публичных портов и Funnel нет; правила Firewall не меняются.
- Ничего не меняется на дисках, в ОС и в настройках безопасности Windows.
