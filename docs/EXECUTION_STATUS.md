## Что значат статусы

| Статус | Значение |
|---|---|
| **Реализовано** | код есть и работает |
| **Проверено автоматически** | есть тесты (unit или Chrome e2e), они проходят |
| **Проверено вручную** | я проверил на этом ПК или на реальной службе |
| **Частично** | сделана часть, остаток указан |
| **Требует внешней настройки** | работает только после установки, аккаунта, домена или согласия владельца |
| **Не реализовано** | кода нет |
| **Заблокировано** | мешает оборудование или решение владельца |

Если возможность требует установки, настройки или действия владельца, она **не считается работающей**, пока это не сделано.

## Известные ограничения среды

- На этом ПК периодически падают процессы (антивирус, служба памяти): тестовый раннер иногда завершается аварийно. Повтор помогает; в `playwright.config.ts` стоит один повтор.
- В сессиях Claude Desktop `node` из PATH может оказаться старой копией в AppData: первым ставьте `C:\FamilyServer\tools\nodejs`.
