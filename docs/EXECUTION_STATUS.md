## P1 — портал (Implemented, 17.10.2026)

### 6.1 Первая административная учётная запись

- **Пользователей до этого не было**: `users.json` отсутствовал.
- **Создан администратор `alex`** («Алекс») командой `scripts\user.cmd add alex --name "Алекс" --role admin --generate-password`.
  - Пароль случайный, около 116 бит.
  - Показан один раз и нигде не сохранён: ни в Git, ни в README, ни в логах. Хранится только хэш scrypt.
  - Действует до 24.10.2026 и только для первого входа.
  - Владелец получил пароль в итоговом сообщении сессии.
- **Сброс.** Если пароль потерян или истёк: `scripts\user.cmd passwd alex --generate-password`.
- **Код.** Стандартного пароля в исходниках нет.
  - Новое: `--generate-password`, обязательная смена временного пароля, `POST /api/password`, страница «Мой профиль».
  - OpenSpec: `openspec/changes/archive/2026-10-17-add-first-admin-and-autostart`.
- **Проверено на рабочем экземпляре `127.0.0.1:8070`:**
  - `alex` входит с временным паролем, получает `mustChangePassword: true`;
  - `/api/services` → 403 `password_change_required`;
  - `/api/session` → 200;
  - временные учётные записи «админ» и «семья» (созданы и сразу удалены):
    - админ: `/api/admin/users` и `/api/admin/audit` → 200;
    - семья: `/api/services` → 200, `/api/admin/users` и `/api/admin/diagnostics` → 403;
  - без сессии → 401, неверный пароль → 401.

### 6.2 Автозапуск

- Задача «FamilyServer» запускает супервизор: S4U, пароль не хранится, окон нет.
  - Триггеры: при включении ПК, при входе, «сторож» каждые 5 минут.
  - Супервизор перезапускает портал после сбоя и зависания, не допускает второго экземпляра, останавливает мягко, ведёт `supervisor.log`.
  - Выключение — `scripts\autostart.cmd -Off`.
  - Подробно — [runbooks/start-stop.md](runbooks/start-stop.md).
- **Проверено:**
  - перезапуск после принудительного завершения — 2,3 с;
  - второй экземпляр завершается;
  - после `stop.cmd` «сторож» ничего не запускает;
  - пробы Tailscale и принтера работают в сеансе S4U.
- **Tailscale Serve** после перезапуска супервизора не изменился: `https://server-home.tail89d77e.ts.net (tailnet only) → http://127.0.0.1:8070`.
- **Ограничение.** Tailscale на Windows подключается после входа пользователя. До входа портал работает только локально.
- **Ручная проверка владельцем:** перезагрузить ПК, не входить в Windows → через 1–2 минуты на самом ПК открывается `http://127.0.0.1:8070`; войти в Windows → портал открывается с телефона.
