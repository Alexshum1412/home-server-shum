| Статус | Значение |
|---|---|
| **Код реализован** | код есть |
| **Проверено автоматически** | есть тесты (unit или Chrome e2e), они проходят |
| **Проверено вручную** | я проверил на этом ПК или на реальной службе; что именно — написано |

## Главное сейчас (честно)

1. **Оборудование нестабильно.** За 16–20.10.2026 журнал Windows: 11 неожиданных выключений, 7 аппаратных ошибок (WHEA), 315 повторов ввода-вывода у неисправного диска `ST_M13FQBL`; установленный Chrome падает при каждом запуске. Это угрожает любой работе и данным; порядок проверки — [owner-actions.md](owner-actions.md), раздел «Оборудование». Тесты в браузере идут на копии Chrome (`E2E_CHROME`).
2. **GitHub: вход истёк.** Код этого этапа локально закоммичен, но на GitHub не отправлен (нужен ваш вход, [owner-actions.md](owner-actions.md), пункт 4/11); ночное зеркало пишет «нет доступа».
3. Tailscale на ПК при последней проверке был **остановлен** (`scripts\status.cmd`): пока он выключен, портал с телефона не открывается.

## Известные ограничения среды

- Установленный `chrome.exe` падает при каждом запуске (0xC0000005 в `chrome.dll`); копия той же папки (`C:\FamilyServer\tools\chrome-copy`, вне Git) работает: `E2E_CHROME=<путь>` для `npm run test:e2e` и `guide:screenshots`. Причину не устанавливали; рядом нестабильность ПК (см. выше).
- В сессиях Claude Desktop `node` из PATH может оказаться старой копией в AppData: первым ставьте `C:\FamilyServer\tools\nodejs`.
- Если тестовый сервер остался на портах 8071–8074 (раннер оборвали), следующий запуск ответит «already used»: освободите порты (живой портал на 8070 не трогать).
