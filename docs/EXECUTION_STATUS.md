- Задача «FamilyServer» запускает супервизор: S4U, пароль не хранится, окон нет.

  - перезапуск после принудительного завершения — 2,3 с;
  - второй экземпляр завершается;
  - после `stop.cmd` «сторож» ничего не запускает;

- **Tailscale Serve** после перезапуска супервизора не изменился: `https://server-home.tail89d77e.ts.net (tailnet only) → http://127.0.0.1:8070`.
- **Ограничение.** Tailscale на Windows подключается после входа пользователя. До входа портал работает только локально.
- **Ручная проверка владельцем:** перезагрузить ПК, не входить в Windows → через 1–2 минуты на самом ПК открывается `http://127.0.0.1:8070`; войти в Windows → портал открывается с телефона.

## P2 — Jellyfin (Implemented, 17.10.2026)

- **Установка.** Официальный ZIP Jellyfin 12.2, SHA-256 сверен. Программа — `C:FamilyServerappsjellyfin`, данные — `C:FamilyServerdatajellyfin`. Запуск — супервизор (ADR-0005).
- **Медиатека.** `C:FamilyDataMedia{Фильмы,Сериалы,Мультфильмы,Домашнее видео,Музыка}`, права — только PC, SYSTEM и администраторы. Готовых медиафайлов на ПК не было. Добавлено законное тестовое видео, созданное ffmpeg: `ФильмыТестовое видео (2026)`. Его можно удалить.
- **Доступ.** Jellyfin слушает только `127.0.0.1:8096`. Семья открывает `https://server-home.tail89d77e.ts.net:8443` (Tailscale Serve, только tailnet). По LAN и Tailscale-IP напрямую соединения нет. Funnel выключен.
- **Администратор Jellyfin.** `alex`, пароль случайный. Показан один раз и передан владельцу в итоговом сообщении. В файлах не хранится.
- **Портал.** «Кинотеатр» ведёт в Jellyfin. Статус берётся из реальной проверки `/health` и состояния супервизора: «Работает», «Остановлен», «Сбой: перезапускается», «Не отвечает».

## P3 — загрузки (Implemented, 17.10.2026)

- **Решение.** Своя очередь прямых HTTP(S)-ссылок внутри портала. Торрентов нет, отдельного веб-интерфейса нет. Почему не qBittorrent и не aria2 — [ADR-0006](decisions/0006-downloads.md).
- **Права.** Право `downloads` выдаётся командой `scripts\user.cmd allow <логин> downloads`. У администраторов оно есть всегда.
- **Подтверждение.** Сначала «Проверить ссылку»: портал показывает имя, размер, сайт и поддержку паузы. Загрузка начинается только после «Скачать».
- **Хранение.** Файлы сохраняются только в `C:\FamilyData\Files\users\<логин>\Загрузки`. Программы и скрипты не сохраняются. Готовые файлы получают метку «из интернета».
- **Защита от SSRF.** Домашняя сеть, tailnet и сам ПК недоступны: проверяется каждое соединение и каждое перенаправление.
- **Лимиты.** Один файл — до 50 ГБ, на диске всегда остаётся не меньше 50 ГБ. Одновременно идут 2 загрузки.

| Проверка | Результат |
|---|---|
| Юнит-тесты `downloads.test.ts` | 13: фильтр адресов, имена, права, полная загрузка байт в байт, пауза/продолжение через Range, отмена, дубликат (409), веб-страница/программа/превышение размера/перенаправление в LAN/404, реальный фильтр против 127.0.0.1 и localhost, мало места (507), недоступная папка (507), чужие загрузки не видны |
| e2e `downloads.spec.ts` | без права — понятное сообщение и 403; ссылка в домашнюю сеть и `ftp://` — понятная ошибка |
| Рабочий портал (Chrome, ширина 390, временный администратор) | OVH `1Mb.dat` скачан, SHA-256 совпал, `Zone.Identifier: ZoneId=3`; `100Mb.dat`: 2,7 МБ/с, пауза на 17 МБ, продолжение с 17 МБ, отмена на 22 МБ, недокачанная часть удалена. Временная учётка и её файлы удалены |

## P4 — семейные файлы и фото (Implemented, 17.10.2026)

- **Проверка Nextcloud и Immich** по официальным требованиям — [ADR-0007](decisions/0007-files-and-photos.md):
  - Nextcloud не поддерживает Windows как сервер;
  - Immich требует Docker/WSL2 (включение компонентов Windows запрещено ТЗ), 6–8 ГБ ОЗУ и не работает с базой на NTFS.
  - Выбран встроенный сервис портала: без новых компонентов и без дополнительной памяти.
- **«Файлы».** Пространства «Личное» (видит только владелец, даже администратор через портал не видит) и «Общее». Есть загрузка с прогрессом, папки, переименование, удаление в корзину (портал ничего не удаляет окончательно), скачивание и просмотр безопасных типов в песочнице.
- **«Фото».** «Мои» и «Общие», папки по месяцам. Загрузка с телефона через браузер, миниатюры делает сам браузер, просмотрщик с перелистыванием. Принимаются только настоящие изображения и видео.
- **Хранение.** `C:\FamilyData\Files\{users\<логин>,shared}`, `C:\FamilyData\Photos\{users\<логин>,shared}`, права — PC, SYSTEM, администраторы.

## P5 — резервное копирование и восстановление (Implemented / Partial, 17.10.2026)

- **Места.** Ежедневно в 03:30 и вручную `scripts\backup.cmd`: диск C: (`C:\FamilyServer\backups`) и флешка «reserve» (`D:\FamilyServerBackups`); код дополнительно отправляется на GitHub. Хранится 14 версий в каждом месте.
- **Состав копии:**
  - данные портала: пользователи (хэши), права, журнал, загрузки, сервисы;
  - `.env`, Git-код, настройки Tailscale Serve;
  - **с 17.10:** семейные файлы, фото с миниатюрами, домашнее видео, настройки и база Jellyfin. Jellyfin на время копирования останавливается через супервизор — измерено 0,4 с.
- **Не входят:** фильмы, сериалы и музыка (их можно найти снова), корзины, недокачанные и временные файлы, кэш и картинки Jellyfin, сессии.
- **Версии.** Неизменённые семейные файлы — жёсткие ссылки на предыдущую копию: место занимает только новое.
- **Целостность.** SHA-256 каждого нового файла проверяется при записи; `verify` перепроверяет всё; `test-restore` восстанавливает во временную папку и сверяет.
- **Отчёт о неудаче.** Ошибка любого места → «ошибка» на дашборде и в `backup.log`. Нехватка места → понятное сообщение с советом.

| Проверка (17.10.2026) | Результат |
|---|---|
| Юнит-тесты `backup-family.test.ts` | 5: состав и исключения, жёсткие ссылки (тот же inode) и полная проверка обеих копий, копия цела после удаления старой, мало места → понятная ошибка и Jellyfin снова запущен, Jellyfin не остановлен → замечание |

- зашифрованная копия вне дома.

## P6 — мониторинг и «Оливия» (Implemented, 17.10.2026)

- **«Состояние системы».** Только измеренные значения: CPU, память, место на дисках, физические диски, Tailscale, принтер (по данным Windows), время последней копии, ошибки и предупреждения.
  - **Новое:** программы сервера — портал и Jellyfin: работает / сбой / остановлен, перезапуски; данные из супервизора проверяются на «живость».
  - **Новое:** общий итог — «Работает / Предупреждение / Ошибка / Неизвестно».
  - Предупреждения о сбое программы видны всем, об остановке и нестабильности — администратору.
- **Лёгкий опрос:** CPU — 5 с, программы — 10 с, место/копии/Tailscale/сервисы — 60 с, диски и принтер — 5 мин.
- **«Оливия»** — помощник на правилах, без нейросети: находки с объяснением и советом. Четыре действия из списка в коде; у каждого проверка применимости, подтверждение, лимит частоты и журнал. Выключается `OLIVIA_ENABLED=0`, мониторинг при этом работает. Почему LLM не ставится — [ADR-0008](decisions/0008-olivia-without-ai.md).
- **Блокировка копирования.** Ночная задача, ручной запуск и «Оливия» не запустят копирование дважды одновременно (`run/backup.lock`).
