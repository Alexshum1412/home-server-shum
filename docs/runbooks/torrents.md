## Что будет скачано (по вашему согласию)

| Что | Откуда | Размер |
|---|---|---|
| `aria2-1.37.0-win-64bit-build1.zip` — торрент-клиент aria2 1.37.0 | github.com/aria2/aria2, релиз `release-1.37.0` | 2 475 379 байт (около 2,4 МБ) |

У релиза на GitHub нет опубликованной контрольной суммы, поэтому в `scripts\components.json` значение SHA-256 для aria2 **пока пустое, и установщик отказывается ставить файл без проверки**. Порядок: после вашего «да» файл скачивается в пустую временную папку, считается SHA-256, сверяется с размером с релиза, и сумма закрепляется в `components.json` (тем же коммитом); дальше установщик проверяет каждый раз. Сумму можно сверить вручную со страницей релиза.

## Установка

```bash
scripts\torrent-setup.cmd
```

Установит в `C:\FamilyServer\apps\aria2`. Затем:

```bash
scripts\service.cmd restart dashboard
```

Супервизор сам запустит `aria2` (если `aria2c.exe` есть и `SUPERVISE_ARIA2` не `0`). Рабочие файлы клиента — `C:\FamilyServer\data\aria2` (сессия, `aria2.conf` с секретом RPC, временная папка). Секрет создаёт портал; в Git он не попадает.

## Как пользоваться

«Загрузки» → вставить магнитную ссылку или выбрать `.torrent` → портал показывает, что внутри и сколько места нужно (программы и скрипты пропускаются) → выбрать, куда сохранить → «Скачать». Очередь показывает состояние, прогресс, скорость, оставшееся время и ошибки; есть пауза, продолжение, отмена и повтор. В медиатеку фильмы кладутся в «Фильмы», «Сериалы», «Мультфильмы» или «Музыка» — после завершения портал просит Jellyfin обновить библиотеку.

## Настройки (`.env`, необязательно)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `TORRENT_RPC_URL` | `http://127.0.0.1:6800/jsonrpc` | только адрес на этом ПК |
| `TORRENT_HOME` | `C:\FamilyServer\apps\aria2` | где лежит `aria2c.exe` |
| `TORRENT_SEED_RATIO` | 1 | сколько отдавать после загрузки (1 = столько же, сколько скачано) |
| `TORRENT_UPLOAD_LIMIT_KB` | 500 | предел отдачи, КБ/с — чтобы дом не остался без интернета |
| `SUPERVISE_ARIA2` | включено | `0` — не запускать клиент |

## Запасной способ

Если клиент не работает, «Загрузки» пишут «Торренты сейчас недоступны» и причину; прямые ссылки продолжают работать. Файл можно скачать на телефон или ПК любым клиентом и положить через «Файлы → Загрузить» или `scripts\import.cmd`.

## Если не работает

| Симптом | Что делать |
|---|---|
| «клиент не установлен» | `scripts\torrent-setup.cmd` |
| «клиент не отвечает» | `scripts\service.cmd status`; журнал `aria2.err.log` |
| Скорость мала | нужен входящий порт на роутере — **портал этого не делает и не требует**; раздач с многими пирами хватает исходящих соединений |
| Не хватает места | освободите диск или выберите другое место; портал не начнёт загрузку, если после неё останется меньше `MIN_FREE_GB` (по умолчанию 50 ГБ) |

## Не проверено

Реальная загрузка живой раздачи, разгон скорости, обновление библиотеки Jellyfin после настоящего завершения (проверено на макете клиента и макете Jellyfin). Проверка возможна сразу после установки на любой законной раздаче (например, образ дистрибутива Linux).
