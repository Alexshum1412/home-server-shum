## Установка (если нужно поставить заново)

```bash
scripts\torrent-setup.cmd
```

Установит в `C:\FamilyServer\apps\aria2`. Затем:

```bash
scripts\service.cmd restart dashboard
```

Супервизор сам запустит `aria2` (если `aria2c.exe` есть и `SUPERVISE_ARIA2` не `0`). Рабочие файлы клиента — `C:\FamilyServer\data\aria2` (сессия, `aria2.conf` с секретом RPC, временная папка). Секрет создаёт портал; в Git он не попадает.

## Как пользоваться

«Загрузки» → вставить магнитную ссылку или выбрать `.torrent` → портал показывает, что внутри и сколько места нужно (программы и скрипты пропускаются) → выбрать, куда сохранить → «Скачать». Очередь показывает состояние, прогресс, скорость, оставшееся время и ошибки; есть пауза, продолжение, отмена и повтор. В медиатеку фильмы кладутся в «Фильмы», «Сериалы», «Мультфильмы» или «Музыка» — после завершения портал просит Jellyfin обновить библиотеку.

## Настройки (`.env`, необязательно)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `TORRENT_RPC_URL` | `http://127.0.0.1:6800/jsonrpc` | только адрес на этом ПК |
| `TORRENT_HOME` | `C:\FamilyServer\apps\aria2` | где лежит `aria2c.exe` |
| `TORRENT_SEED_RATIO` | 1 | сколько отдавать после загрузки (1 = столько же, сколько скачано) |
| `TORRENT_UPLOAD_LIMIT_KB` | 500 | предел отдачи, КБ/с — чтобы дом не остался без интернета |
| `SUPERVISE_ARIA2` | включено | `0` — не запускать клиент |

## Запасной способ

Если клиент не работает, «Загрузки» пишут «Торренты сейчас недоступны» и причину; прямые ссылки продолжают работать. Файл можно скачать на телефон или ПК любым клиентом и положить через «Файлы → Загрузить» или `scripts\import.cmd`.

## Если не работает

| Симптом | Что делать |
|---|---|
| «клиент не установлен» | `scripts\torrent-setup.cmd` |
| «клиент не отвечает» | `scripts\service.cmd status`; журнал `aria2.err.log` |
| Скорость мала | нужен входящий порт на роутере — **портал этого не делает и не требует**; раздач с многими пирами хватает исходящих соединений |
| Не хватает места | освободите диск или выберите другое место; портал не начнёт загрузку, если после неё останется меньше `MIN_FREE_GB` (по умолчанию 50 ГБ) |

## Проверка на настоящей раздаче (18.10.2026)

Проверка идёт скриптом `tests\live\torrent-lifecycle.mjs <файл.torrent> --sha256 <сумма>`: он запускает настоящий `aria2c.exe` и **отдельную** копию портала с временными папками (папок семьи не касается) и проводит одну законную раздачу через все шаги: проверка → добавление → отмена → повтор → пауза → продолжение → завершение → хэш результата.

Раздача — установочный образ Debian 13.7.0 (netinst, `debian-13.7.0-amd64-netinst.iso`). `.torrent`, `SHA256SUMS` и подпись взяты с официального сайта Debian; подпись `SHA256SUMS.sign` проверена GnuPG (ключ Debian CD signing key, отпечаток `DF9B 9C49 EAA9 2984 3258 9D76 DA87 E80D 6294 BE9B`; сам ключ получен по HTTPS, доверие к нему не «подтверждено цепочкой» — GnuPG честно пишет об этом).

| Что | Результат |
|---|---|
| Файл | 792 723 456 байт; **SHA-256 совпал** с опубликованным в подписанном `SHA256SUMS` (`a7ef94ac…e355`), пересчитан повторно 20.10.2026 |
| Отмена и повтор | отмена снимает загрузку со списка, повторное добавление того же `.torrent` продолжает с уже скачанного — **проверено на настоящей раздаче** (в журнале: добавление, отмена, добавление, завершение) |
| Общее время | около 4 минут (10:27 → 10:31 по журналу), скорость порядка 3 МБ/с |
| Пауза и продолжение | шаг есть в скрипте, но **результат этого шага в журнале не сохранился**: пауза и продолжение проверены автоматически на макете клиента, на настоящей раздаче — не подтверждены; повторите скриптом, если это важно |
| Отдача | ограничена `TORRENT_UPLOAD_LIMIT_KB` (500 КБ/с по умолчанию); реальный пик отдачи не записан |
| Обновление Jellyfin по завершении | **не проверено на настоящей раздаче**: проверено на макете Jellyfin; в испытании файл лёг в папку временной учётной записи, а не в медиатеку |

Тестовые папки остались на диске (`C:\FamilyServer\downloads\lifecycle-*`, `debian-13.7.0-test`, `aria2-1.37.0-check`): вне Git и вне резервных копий; ничего не удаляли. Образ Debian (около 0,8 ГБ) можно удалить вручную, он нужен только для проверки.

## Не проверено

- Пауза и продолжение на настоящей раздаче (см. выше).
- Обновление библиотеки Jellyfin после настоящего завершения в медиатеку.
- Разгон на быстрой раздаче и поведение при нехватке места (проверено только автотестами).
