# Ранбук: резервное копирование и восстановление

**Статус: Not configured / Blocked.** Резервное копирование не настроено, и дашборд честно показывает предупреждение «Резервные копии не настроены».

## Почему не настроено

- В ПК один рабочий диск (`C:`). Второй накопитель определяется как неисправный (`ST_M13FQBL`, см. `docs/environment-audit.md`).
- Копия на тот же диск защищает только от случайного удаления, но не от отказа диска, кражи, скачка напряжения или пожара.
- Выбор внешнего/облачного места — решение владельца (данные семьи, ключи шифрования).

## Что копировать (когда появится место)

| Что | Где | Критичность |
|---|---|---|
| Данные дашборда | `%LOCALAPPDATA%\FamilyDashboard` (пользователи с хэшами паролей, сессии, `services.json`, журнал) | средняя; копировать только зашифрованно вне ПК |
| Код дашборда | `C:\Users\PC\Desktop\THE DASHBOARD` (Git) | низкая — восстановим из Git |
| Будущие семейные фото и документы | `C:\FamilyData\...` (после установки сервисов) | **высокая** |
| Конфигурации и базы будущих сервисов | их каталоги данных | высокая |

## План (следующий этап)

1. Купить/выделить внешний диск USB 2+ ТБ (или исправный второй внутренний диск).
2. Выбрать инструмент с версионностью и шифрованием (кандидаты: restic/Kopia; встроенная «История файлов» Windows — проще, но без шифрования) — после проверки официальной документации.
3. Ежедневная задача + `backup-status.json` в каталоге данных дашборда (поля `lastRunAt`, `lastResult`, `lastSuccessAt`, `restoreTestedAt`) — дашборд сразу начнёт показывать реальный статус.
4. **Тест восстановления**: восстановить тестовый файл в отдельную папку, сравнить хэш, записать `restoreTestedAt`. Без этого бэкап не считается рабочим.
5. Вторая копия вне дома (зашифрованная) — только по решению владельца.

## Ручная копия данных дашборда сейчас (временно)

Остановить дашборд (`scripts\stop.cmd`) и скопировать папку `%LOCALAPPDATA%\FamilyDashboard` на внешний носитель. Восстановление: остановить дашборд, вернуть папку на место, запустить `scripts\start.cmd`.
