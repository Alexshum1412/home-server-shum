# Права процессов сервера: что сейчас и план перехода к минимальным правам

_Состояние проверено 18.10.2026 командой `scripts\privileges-report.cmd` (только чтение). **Ничего из плана ниже ещё не применено**: это решение владельца, оно меняет защиту Windows и требует перезагрузки._

## Что есть сейчас

| Факт | Следствие |
|---|---|
| Контроль учётных записей (**UAC**) выключен (`EnableLUA=0`) | у любой программы, запущенной администратором, полные права без запроса |
| Супервизор, портал, Jellyfin и торрент-клиент запущены одной учётной записью — той, что состоит в группе «Администраторы» | взлом любой из программ (например, торрент-клиента, который принимает данные из интернета) даёт полный доступ к компьютеру |
| Задача планировщика «FamilyServer»: пользователь = администратор, тип входа S4U (пароль не хранится), уровень «обычный» | при выключенном UAC «обычный» уровень на деле не ограничивает |
| На папки данных (`C:\FamilyServer\data`, `C:\FamilyData`) право записи у администраторов, SYSTEM и этой же учётной записи | отдельных ограничений для программ нет |
| Папки `C:\FamilyServer\secrets` (ключ шифрования копий) пока нет | ключ появится при `backup.cmd offsite init-key` |

Что уже ограничено кодом, независимо от прав Windows: портал и Jellyfin слушают только `127.0.0.1`; торрент-клиент принимает управление только на `127.0.0.1` с секретом; модель слушает только `127.0.0.1`; портал не запускает произвольные команды; загруженные программы (.exe, .bat …) не принимаются и не запускаются.

## Цель

1. **UAC включён.**
2. Портал, Jellyfin, торрент-клиент и модель работают под **отдельной учётной записью без прав администратора** (`familysvc`) и могут писать только в свои папки.
3. Ваша учётная запись администратора используется только для управления.
4. Автозапуск и перезапуск после сбоя продолжают работать.

Разделить программы между **разными** учётными записями (отдельная для торрент-клиента и для модели) Windows позволяет только через отдельную задачу планировщика на каждую; нынешний супервизор запускает все программы от своего имени, поэтому это отдельная доработка (не сделана): этап 2 ниже.

## Перед началом (обязательно)

1. Свежая копия и проверка: `scripts\backup.cmd`, `scripts\backup.cmd test-restore`.
2. Запомните текущее состояние: `scripts\privileges-report.cmd > %USERPROFILE%\privileges-before.txt`.
3. Убедитесь, что вы **знаете пароль** своей учётной записи администратора и можете войти в Windows (после включения UAC для входа всё равно нужен пароль).
4. Найдите время, когда никто не пользуется порталом: потребуются перезагрузка и 15–30 минут.

## Этап 1. Отдельная учётная запись службы (команды от имени администратора, PowerShell)

> Команды ниже **не выполнялись**; перед запуском прочитайте каждую.

```powershell
# 1. Обычная локальная учётная запись, пароль — длинный случайный, запишите его в менеджер паролей
$password = Read-Host -AsSecureString 'Пароль для familysvc'
New-LocalUser -Name 'familysvc' -Password $password -PasswordNeverExpires -UserMayNotChangePassword -Description 'Семейный сервер: службы без прав администратора'
# (в группу «Администраторы» не добавляется; «Пользователи» добавляется автоматически)

# 2. Права на папки: изменение — только там, где службы пишут; чтение и запуск — где только читают
icacls 'C:\FamilyServer\data'   /grant 'familysvc:(OI)(CI)M' /T
icacls 'C:\FamilyData'          /grant 'familysvc:(OI)(CI)M' /T
icacls 'C:\FamilyServer\downloads' /grant 'familysvc:(OI)(CI)M' /T
icacls 'C:\FamilyServer\apps'   /grant 'familysvc:(OI)(CI)RX' /T
icacls 'C:\FamilyServer\tools'  /grant 'familysvc:(OI)(CI)RX' /T
icacls 'C:\Users\PC\Desktop\THE DASHBOARD' /grant 'familysvc:(OI)(CI)RX'
icacls 'C:\Users\PC\Desktop\THE DASHBOARD\dist' /grant 'familysvc:(OI)(CI)RX' /T
# модели лежат в data\models: чтение достаточно, запись не нужна
# ключ шифрования копий (secrets) службе НЕ нужен: копии шифрует ежедневная задача копирования
```

Замечание: папка проекта лежит на рабочем столе администратора, поэтому нужно ещё право «обход папок» на `C:\Users\PC` и `Desktop`. Надёжнее перенести проект в `C:\FamilyServer\app` (копия кода и `.env`) и запускать оттуда — это отдельный шаг с проверкой путей в `.env`, `scripts\*.ps1` и задаче планировщика.

```powershell
# 3. Задача «FamilyServer» — запускать от familysvc. Перед этим сохраните описание задачи для отката:
Export-ScheduledTask -TaskName 'FamilyServer' | Out-File "$env:USERPROFILE\FamilyServer-task-before.xml" -Encoding utf8
# затем смените пользователя задачи (пароль спросит Windows):
#   Планировщик заданий → FamilyServer → Свойства → «Изменить пользователя или группу…» → familysvc,
#   «Запускать независимо от того, вошёл ли пользователь в систему», «Выполнять с наивысшими правами» — НЕ ставить.
# 4. Включить UAC и перезагрузить:
Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System' -Name EnableLUA -Value 1
Restart-Computer
```

## Проверка после перезагрузки

1. `scripts\privileges-report.cmd`: UAC включён; супервизор, портал, Jellyfin, aria2 — от `familysvc`, и `familysvc` **не** в группе администраторов.
2. `scripts\status.cmd`, `scripts\doctor.cmd`: портал, Jellyfin, торрент-клиент работают; `https://<имя-сервера>.<tailnet>.ts.net` открывается с телефона.
3. `scripts\backup.cmd` и `scripts\backup.cmd test-restore` проходят (копирование идёт от вашей учётной записи — у неё доступ к флешке).
4. Просмотр фильма и загрузка тестового торрента работают.
5. Попытайтесь из-под `familysvc` открыть `C:\Users\PC\Documents` — доступа быть не должно.

## Откат

1. Планировщик → FamilyServer → вернуть прежнего пользователя (или `Register-ScheduledTask -Xml (Get-Content "$env:USERPROFILE\FamilyServer-task-before.xml" -Raw) -TaskName FamilyServer -Force`).
2. `Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System' -Name EnableLUA -Value 0` и перезагрузка.
3. Права `icacls` ничего не отбирают у прежних пользователей, поэтому откатывать их не нужно; учётную запись `familysvc` можно оставить или отключить: `Disable-LocalUser familysvc`.

## Этап 2 (по желанию, позже): разные учётные записи для торрент-клиента и модели

Торрент-клиент принимает данные из интернета, модель разбирает текст людей — для них полезны собственные узкие права: aria2 пишет только в `C:\FamilyServer\data\aria2` и папки назначения, модель читает только `C:\FamilyServer\data\models`. Для этого каждой программе нужна своя задача планировщика с собственной учётной записью, а супервизору — научиться запускать и останавливать их как задачи. Это изменение кода (`server/src/supervisor`) и отдельный OpenSpec; пока не выполнено.

## Риски и что может сломаться

- Скрипты, которым нужны права администратора (`lan-mode.cmd`, правила брандмауэра), после включения UAC попросят подтверждение — это нормально.
- Если путь проекта остался на рабочем столе администратора, службе нужен доступ и к нему (см. замечание выше).
- Windows 10 вышла из обычной поддержки: минимальные права важнее, чем когда-либо, но не заменяют обновления ([windows-support.md](windows-support.md)).
