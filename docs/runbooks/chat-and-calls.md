# Чат, звонки и уведомления

Устройство и решения — [ADR-0012](../decisions/0012-family-chat-and-calls.md). Здесь — что настроить, как проверить и чего ждать от разных устройств.

## Статус на 20.10.2026

| Функция | Статус |
|---|---|
| Личные и групповые чаты, файлы и картинки, прочитано/доставлено | Реализовано; проверено автоматически (тесты сервера и Chrome) |
| Уведомления в портале и на значке | Реализовано; проверено автоматически |
| Web Push на телефон | Реализовано; шифрование проверено по тестовому вектору RFC; **на настоящем телефоне не проверено** |
| Голосовые и видеозвонки между двумя окнами на одном ПК | Проверено автоматически (настоящее WebRTC, тестовые камера и микрофон) |
| Звонок между двумя **разными** устройствами в разных сетях | **Не проверено — требует вас**; пока не настроен TURN |
| TURN | **Требует внешней настройки**; STUN тоже не включён. Код получения временных логинов у Cloudflare Realtime TURN готов и проверен автоматически на макете (`server/test/calls-relay.test.ts`); настоящий ключ Cloudflare **не создан** (нужна ваша учётная запись) |

## Настройка звонков (`.env`, необязательно)

| Переменная | Смысл |
|---|---|
| `CALLS_STUN_URLS` | адреса STUN через запятую: `stun:host:3478` |
| `CALLS_TURN_URLS` | адреса TURN: `turn:host:3478?transport=udp,turns:host:5349` |
| `CALLS_TURN_SECRET` | общий секрет TURN-сервера (не в Git!) |
| `CALLS_TURN_TTL_SEC` | срок временных логинов, 3600 по умолчанию |
| `CALLS_CF_TURN_KEY_ID` | идентификатор ключа Cloudflare Realtime TURN (32 шестнадцатеричных символа) |
| `CALLS_CF_TURN_TOKEN_FILE` | **путь к файлу** с токеном API этого ключа (файл вне проекта; токен не кладётся ни в `.env`, ни в Git) |

Без этих настроек звонок соединяет устройства, которые видят друг друга напрямую (одна сеть, одна tailnet). Для разных сетей нужен ретранслятор (TURN). Что выбрать — результат разбора ниже.

### Разбор вариантов TURN (20.10.2026)

Ограничения: проект не открывает порты на роутере, не ставит Docker/WSL и ничего не отправляет наружу без вашего решения. Через ретранслятор идёт только зашифрованный (DTLS-SRTP) звук и видео и служебные адреса устройств; портал, сообщения и файлы через него не ходят.

| Вариант | Плюсы | Минусы | Решение |
|---|---|---|---|
| **Tailscale у всех участников** | уже есть; устройства соединяются напрямую или через ретрансляторы Tailscale (DERP); ничего не настраивать | у участника должен быть Tailscale; без него звонок невозможен | **основной путь** для семьи |
| **Cloudflare Realtime TURN** (`CALLS_CF_TURN_*`) | не нужен свой сервер и открытые порты; поддерживает TURN поверх TLS (проходит через строгие сети); временные логины, портал выдаёт их на время звонка | нужна ваша учётная запись Cloudflare; трафик ретрансляции идёт через Cloudflare (видит адреса, но не содержимое); платная схема после бесплатного лимита | **рекомендуемое дополнение**, если нужны звонки родственникам без Tailscale |
| coturn на этом ПК | всё своё | нужно открыть порты 3478/5349 на роутере — **этого проект не делает**; ПК дома — ретранслятор для звонков из мобильных сетей нагружает домашний канал | только по решению владельца |
| coturn на недорогом облачном сервере | всё своё, порты открыты там | платный сервер, его нужно обслуживать и обновлять | запасной вариант |
| Публичный STUN (Google и др.) | бесплатно | выдаёт им IP устройства; без TURN не помогает за строгим NAT | по умолчанию **не включён** |

Цены Cloudflare по состоянию на 20.10.2026 (по их документации [Realtime TURN FAQ](https://developers.cloudflare.com/realtime/turn/faq/) и [тарифам](https://developers.cloudflare.com/realtime/pricing/)): бесплатно первые 1 000 ГБ в месяц, дальше 0,05 доллара за ГБ исходящего от Cloudflare трафика; STUN `stun.cloudflare.com` бесплатный. Семейных звонков на несколько часов в месяц это не достигает (видеозвонок — порядка 0,3–1 ГБ в час на участника, оценка по типичным значениям, не замер). **Сверьте цифры на странице тарифов перед включением**: они меняются, и страницы датированы августом 2026 года.

### Как включить Cloudflare Realtime TURN (делает владелец)

1. В панели Cloudflare (dash.cloudflare.com, раздел Realtime → TURN Server) создайте ключ TURN. Cloudflare покажет идентификатор ключа и токен API **один раз**.
2. Токен сохраните в файл **вне проекта**, например `C:\FamilyServer\secrets\cf-turn.token` (UTF-8, одна строка; в Git и в копии он не попадает, если файл лежит вне папки проекта и данных портала; права — только ваша учётная запись).
3. В `.env` добавьте `CALLS_CF_TURN_KEY_ID=<идентификатор>` и `CALLS_CF_TURN_TOKEN_FILE=C:\FamilyServer\secrets\cf-turn.token`, затем `scripts\restart.cmd`.
4. Проверьте звонок двумя устройствами в разных сетях (ниже). Если Cloudflare не ответит, звонки просто идут без ретранслятора — сообщение об этом в журнале портала.

Свой TURN вместо Cloudflare: coturn в режиме `use-auth-secret` с тем же значением `CALLS_TURN_SECRET`; портал выдаёт каждому участнику временный логин на время звонка.

Через Tailscale оба устройства обычно соединяются напрямую — для семьи, где у всех он включён, TURN можно не ставить.
## Как проверить настоящий звонок двумя устройствами (вам)

1. Телефон: Tailscale включён, откройте портал, войдите под своей учётной записью, разрешите микрофон и камеру.
2. Ноутбук или ПК: войдите как другой человек.
3. В «Чате» откройте личный разговор → «Позвонить». На втором устройстве появится входящий звонок. Ответьте, проверьте звук в обе стороны и видео.
4. Повторите, выключив Tailscale на телефоне и включив только мобильную связь, если настроен внешний адрес и TURN: звонок должен соединиться или честно сказать «не удалось соединиться».
5. Результат (получилось/нет, по какой сети) запишите в [owner-actions.md](../owner-actions.md).

## Ограничения устройств (PWA)

- **iPhone/iPad.** Push работает только у портала, добавленного «На экран Домой» (iOS 16.4 и новее). В обычной вкладке Safari — нет. Звонок принимается только при открытом портале: iOS не показывает полноэкранный входящий звонок для сайтов. Если вкладку закрыли, придёт только push (если разрешён).
- **Android (Chrome).** Push работает и из вкладки, и из установленного портала; при включённой экономии заряда уведомления могут задерживаться.
- **Компьютер.** Push в Chrome/Edge работает при запущенном браузере.
- Звук входящего звонка в закрытой вкладке не воспроизводится — только системное уведомление.
- Съёмка камерой и микрофон требуют HTTPS: через Tailscale Serve и туннель он есть; по `http://` домашней сети камера и микрофон **не** включатся (ограничение браузеров).

## Уведомления: что приходит

Новое сообщение, входящий звонок, завершённая или неудавшаяся загрузка, неудачная копия, мало места, остановленный критический сервис, завершённая печать. Каждый человек включает и выключает виды на странице «Уведомления» (там же включается push на этом устройстве) и решает, показывать ли текст сообщения. Ключи Web Push создаются автоматически в `push-vapid.json` в папке данных портала (входит в копию, в Git не попадает).

## Если не работает

| Симптом | Что делать |
|---|---|
| Сообщения приходят только после обновления страницы | проверьте, что страница онлайн (значок связи вверху); портал сам переподключается и перечитывает список |
| «Не удалось соединиться» при звонке | разные сети без TURN → настройте TURN или используйте Tailscale |
| Нет push на iPhone | добавьте портал «На экран Домой», откройте его оттуда и разрешите уведомления |
| Камера не включается | страница открыта по `http://` (не HTTPS) или нет разрешения у браузера |
