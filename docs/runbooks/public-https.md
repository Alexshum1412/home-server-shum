# Дополнительный защищённый HTTPS-адрес (Cloudflare Tunnel)

Статус на 18.10.2026: **Требует внешней настройки.** Политика каналов в портале готова и проверена автотестами ([ADR-0013](../decisions/0013-remote-access-public-https.md)); сам туннель не создан — для него нужны ваша учётная запись Cloudflare и домен. Пока `PUBLIC_HTTPS_URL` пуст, портал работает как раньше: только Tailscale, домашняя сеть и сам ПК.

**Когда это нужно.** Родственнику неудобно или не получается поставить Tailscale (например, на чужом компьютере), а чат, файлы и фото нужны. Основной путь остаётся Tailscale: через туннель — только обычные функции.

## Что останется закрытым через туннель, что бы вы ни настроили

Администрирование и учётные записи, управление сервисами, диагностика, печать, запуск и управление загрузками, поток фильмов (по умолчанию), вход администратора. Список — в ADR-0013. Туннель — не вход: пароль портала нужен всегда.

## Что потребуется от вас

1. Учётная запись Cloudflare (бесплатный план) и домен, добавленный в Cloudflare (можно недорогой; для бесплатных `*.trycloudflare.com` постоянного адреса нет).
2. Права администратора Windows один раз — установить `cloudflared` как службу (это изменение системы, поэтому проект делает не сам).
3. 15 минут.

Скачивание `cloudflared.exe` (около 40 МБ, github.com/cloudflare/cloudflared, релиз для Windows amd64) выполняете вы или даёте мне явное согласие — без него я его не скачиваю.

## Порядок

1. **Туннель.** В панели Cloudflare Zero Trust → Networks → Tunnels → Create (тип cloudflared). Имя, например, `family-server`. Панель покажет команду установки с токеном — **токен не публикуйте и не кладите в Git**.
2. **Маршрут.** Public hostname: `family.ВАШ-ДОМЕН` → Service: `http://127.0.0.1:8070`. Больше никаких маршрутов, особенно на порт 8096 (Jellyfin) и 6800 (торрент-клиент).
3. **Cloudflare Access (обязательно).** Zero Trust → Access → Applications → Add → Self-hosted, адрес `family.ВАШ-ДОМЕН`; политика Allow только для электронных адресов вашей семьи, способ входа — одноразовый код на почту. Это второй замок снаружи: портал сначала не увидит запрос, пока человек не подтвердит почту. Пароль портала остаётся.
4. **Портал.** В `.env` (UTF-8 без BOM):
   ```
   PUBLIC_HTTPS_URL=https://family.ВАШ-ДОМЕН
   ```
   затем `scripts\service.cmd restart dashboard`. Настройка принимает только `https://имя.домен`: адрес Tailscale и IP-адрес отклоняются.
5. **Проверка** с телефона на мобильной связи без Tailscale: открыть адрес → Access просит почту → портал просит логин → видна синяя плашка «Вы вошли через внешний адрес». Проверьте, что `https://family.ВАШ-ДОМЕН/admin` не открывает администрирование (403), а вход `alex` отвечает «Администратор входит только через Tailscale…».

## Настройки (`.env`, необязательно)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PUBLIC_HTTPS_URL` | пусто (канала нет) | имя, на которое отвечает туннель |
| `PUBLIC_ALLOW_ADMIN_LOGIN` | `0` | `1` — разрешить администратору вход и через этот адрес (всё равно без администрирования). Не рекомендуется |
| `PUBLIC_ALLOW_MEDIA_STREAM` | `0` | `1` — разрешить смотреть фильмы через туннель. Условия бесплатного плана Cloudflare не предназначены для видео; на ваш риск |

## Что учесть

- **Cloudflare видит трафик** (TLS заканчивается у них). Если это неприемлемо для семейной переписки — не включайте туннель: Tailscale этого не требует. Ничего не отправляется туда, пока вы сами не включите туннель.
- Размер загрузки через бесплатный план ограничен (около 100 МБ на запрос); больше — через Tailscale.
- Звонки: сигналы идут через туннель, а медиа — по WebRTC напрямую или через TURN (см. [chat-and-calls.md](chat-and-calls.md)). Сам туннель медиа звонка не переносит.
- Если ПК или домашний интернет выключены, туннель не работает так же, как и Tailscale.
- Отозвать доступ: удалить пользователя из политики Access, отключить маршрут или очистить `PUBLIC_HTTPS_URL` и перезапустить портал.

## Если не работает

| Симптом | Причина |
|---|---|
| 421 «неизвестный адрес сервера» | имя в маршруте не совпадает с `PUBLIC_HTTPS_URL` или туннель подменяет заголовок `Host` — не задавайте `httpHostHeader` |
| 403 «недоступно через внешний адрес» на нужной странице | действие закрыто политикой каналов; используйте Tailscale |
| Вход бесконечно просит пароль | браузер блокирует куки третьих сторон? Откройте адрес целиком, а не во фрейме |
| Чат «замирает» | туннель закрыл долгое соединение; портал присылает сигналы-пульс, страница переподключается сама |
