# Ранбук: сетевой доступ

## Адреса

| Где | Адрес | Условия |
|---|---|---|
| На самом сервере | `http://127.0.0.1:8070` | дашборд запущен |
| Любое устройство в tailnet (дома и за границей) | `https://server-home.tail89d77e.ts.net` | на устройстве включён Tailscale, ПК включён, в Windows выполнен вход, дома есть интернет |
| Домашняя сеть без Tailscale и без интернета | `http://<адрес ПК>:8070` | по умолчанию выключен; включает владелец: «Запасной адрес в домашней сети» ниже |

## Включить / выключить частный HTTPS (Tailscale Serve)

```bat
scripts\serve-tailnet.cmd
```
```bat
scripts\serve-tailnet.cmd -Off
```

Скрипт выполняет `tailscale serve --bg --https=443 http://127.0.0.1:8070`, а при `-Off` — `tailscale serve --https=443 --set-path / off`, то есть удаляет **только** адрес дашборда. Он отказывается что-либо менять, если на порту 443 есть чужие настройки Serve, и никогда не трогает Funnel. Проверка:

```bat
"C:\Program Files\Tailscale\tailscale.exe" serve status
```

Ожидается `https://server-home.tail89d77e.ts.net (tailnet only)` и `|-- / proxy http://127.0.0.1:8070`.

## Проверка с другого устройства

1. На телефоне включить Tailscale (тот же аккаунт/tailnet).
2. Открыть `https://server-home.tail89d77e.ts.net` — должна открыться страница входа без предупреждений о сертификате.
3. Выключить Tailscale на телефоне — адрес не должен открываться (доступа из интернета нет).

## После перезагрузки ПК

Tailscale на Windows по умолчанию подключается только после входа пользователя в Windows. Варианты (решение владельца):
- входить в Windows после перезагрузки (проще всего);
- включить в Tailscale «Run unattended» (меню в трее → Preferences) — тогда Tailscale работает без входа, но управлять им сможет только включивший пользователь.

Сам портал (и Jellyfin) стартует **при включении компьютера, ещё до входа**: так работает задача планировщика «FamilyServer» (`scripts\autostart.cmd`, выключить — `scripts\autostart.cmd -Off`; подробно — `start-stop.md`). Но пока Tailscale не подключён, портал доступен только на самом ПК.

## Запасной адрес в домашней сети (готов, по умолчанию выключен)

Нужен, когда дома пропал интернет, а портал нужен с телефона в той же Wi‑Fi сети (Tailscale без интернета дома не гарантируется). Портал при этом слушает свой адрес в домашней сети **дополнительно** к `127.0.0.1` — не все адреса компьютера.

```bat
scripts\lan-mode.cmd status
scripts\lan-mode.cmd on
scripts\lan-mode.cmd off
```

- `status` ничего не меняет: показывает настройку, правило брандмауэра и адреса ПК.
- `on` выполняет **владелец** в PowerShell «от имени администратора», потому что меняет настройки безопасности Windows. Перед этим скрипт показывает, что сделает, и спрашивает «ДА». Он делает ровно три вещи:
  1. создаёт одно правило входящих подключений «Family Dashboard (LAN, 8070)»: только профиль «Частная сеть», только локальная подсеть, только этот адрес и порт, только `node.exe` проекта;
  2. записывает в `.env` две строки: `LAN_BIND=<адрес ПК>` и `LAN_URL=http://<адрес ПК>:8070`;
  3. перезапускает портал.
- `off` убирает правило и обе строки.

Проверено 17.10.2026 (без включения правила): портал на реальном адресе ПК `192.168.1.252` отвечает, на чужой заголовок `Host` отвечает 421, слушает только `127.0.0.1` и этот адрес. С другого устройства это можно проверить только после `on`.

**Ограничения.** Обычный HTTP без шифрования: установить портал как приложение по нему нельзя. Адрес виден всем устройствам домашней сети; вход по паролю обязателен, а попытки подбора ограничены. Лучше закрепить IP ПК за его сетевой картой в роутере: после смены адреса запасной путь перестанет открываться (`lan-mode.cmd status` и «Подключение» у администратора покажут проблему). Если адрес задан, а портал его не слушает, администратор видит причину на странице «Подключение».

## Что работает без интернета

- Дома: локальный адрес на самом ПК; запасной адрес в домашней сети, если включён. Сервисы, которым не нужен интернет (Jellyfin в будущем), продолжают работать.
- Из-за границы: ничего — без домашнего интернета Tailscale не может достучаться до ПК.
- Установленная PWA откроет только «оболочку» и покажет «Нет связи с домашним сервером».
