# Ранбук: запуск, остановка, автозапуск, обновление

Все команды запускаются из папки проекта `C:\Users\PC\Desktop\THE DASHBOARD`. Двойной щелчок по `.cmd` тоже работает.
- Node.js скрипты берут из `C:\FamilyServer\tools\nodejs\node.exe`.
- Данные и логи лежат в `C:\FamilyServer\data\dashboard`.

## Как устроен запуск (Implemented, 17.10.2026)

Портал и Jellyfin запускает не пользователь, а **супервизор** — `server\src\supervisor\main.ts`. Список программ задан в коде, `supervisor\apps.ts`. Супервизор:
- после сбоя перезапускает программу через 1, 2, 4… до 60 с;
- если программа зависла (3 проверки `/health` подряд без ответа после времени на старт), перезапускает её;
- останавливает мягко: портал — командой по IPC, Jellyfin — через его API; после тайм-аута завершает принудительно;
- работает в единственном экземпляре — блокировка через именованный канал. Второй экземпляр сразу завершается.

Супервизор запускает **задача планировщика «FamilyServer»**:

| Параметр | Значение |
|---|---|
| Учётная запись | `SERVER-HOME\PC`, обычные права (RunLevel Limited) |
| Режим | S4U — пароль Windows не хранится, окон нет (сеанс 0) |
| Триггеры | при включении компьютера (до входа в Windows); при входе пользователя; каждые 5 минут — «сторож» |
| Несколько экземпляров | не запускать второй (`IgnoreNew`) |
| Лимит времени | нет |

> **Ограничение.** До входа в Windows портал работает, но открыть его можно только на самом ПК. Tailscale на Windows по умолчанию подключается после входа пользователя (см. `network.md`, «После перезагрузки ПК»). Поэтому «удалённый доступ сразу после перезагрузки» без входа в Windows **не обещается**.

## Команды

| Действие | Команда | Что происходит |
|---|---|---|
| Запустить | `scripts\start.cmd` | проверяет Node и зависимости, при необходимости собирает интерфейс, снимает отметку «остановлено», запускает задачу «FamilyServer» (или супервизор в этом сеансе, если автозапуск выключен), ждёт `/api/health` до 40 с |
| Остановить | `scripts\stop.cmd` | команда `shutdown` супервизору: мягко останавливает портал и Jellyfin, затем сам супервизор. Оставляет отметку `run\supervisor-stopped.json`, поэтому «сторож» не запустит всё снова до `start.cmd` или перезагрузки |
| Состояние | `scripts\status.cmd` | супервизор и программы (работает / сбой / перезапусков), ответ портала, порты, автозапуск, Tailscale Serve |
| Включить автозапуск | `scripts\autostart.cmd` | создаёт задачу «FamilyServer». Права администратора нужны один раз; без них — запасной режим «только при входе», без «сторожа» |
| Выключить автозапуск | `scripts\autostart.cmd -Off` | удаляет задачу; работающий портал не останавливает |
| Перезапустить одну программу | `"C:\FamilyServer\tools\nodejs\node.exe" --env-file-if-exists=.env server\src\supervisor\main.ts restart dashboard` (или `jellyfin`) | мягкий перезапуск через супервизор |
| Частный HTTPS | `scripts\serve-tailnet.cmd` / `-Off` | см. `network.md` |
| Резервная копия сейчас | `scripts\backup.cmd` | см. `backup-restore.md` |
| Ежедневная копия | `scripts\backup-schedule.cmd` / `-Off` | задача «FamilyServerBackup», 03:30 |
| Режим разработки | `npm.cmd run dev` | API :8070 с автоперезапуском + Vite :5173; Ctrl+C — остановить. Перед этим `scripts\stop.cmd`: порт 8070 занимает рабочий портал |

Остановка безопасна в любой момент: пользователи, сессии и журнал записываются на диск атомарно сразу при изменении.

## Пользователи

```bat
scripts\user.cmd add mama --name "Мама" --role family --generate-password
scripts\user.cmd add papa --name "Папа" --role family
scripts\user.cmd list
scripts\user.cmd passwd mama --generate-password
scripts\user.cmd role mama admin
scripts\user.cmd remove mama --yes
```

- **`--generate-password`** — команда сама создаёт случайный **временный** пароль, например `xxxxx-xxxxx-xxxxx-xxxxx`.
  - Пароль показывается один раз и нигде не сохраняется, хранится только его хэш.
  - Действует 7 дней и только для первого входа: портал сразу попросит придумать свой пароль, и до этого ничего другого не откроется.
  - Удобно, чтобы выдать родственнику доступ или сбросить забытый пароль.
- **Без параметра** пароль вводится дважды и не отображается, минимум 10 символов.
- Свой пароль каждый может сменить в портале: «Ещё» → «Мой профиль».
- Последнего администратора удалить или понизить нельзя.
- Смена пароля завершает все сессии этого пользователя.
- Изменения подхватываются работающим сервером за пару секунд.

## Обновление кода

```bat
scripts\stop.cmd
git pull            (или скопировать новую версию)
npm.cmd ci
npm.cmd run check
scripts\start.cmd
```

Каталог данных `C:\FamilyServer\data\dashboard` при обновлении не трогается. Перед крупным обновлением полезно сделать копию: `scripts\backup.cmd`.

## Логи

Все логи — в `C:\FamilyServer\data\dashboard\logs\`.

| Лог | Что в нём |
|---|---|
| `supervisor.log` | старты, сбои с кодом выхода, перезапуски, остановки |
| `dashboard.out.log` | журнал портала |
| `dashboard.err.log` | ошибки конфигурации |
| `jellyfin.out.log`, `jellyfin.err.log` | вывод Jellyfin. Его собственные логи — `C:\FamilyServer\data\jellyfin\log` |
| `backup.log` | журнал копирования |

Логи больше 5 МБ (у `supervisor.log` — 2 МБ) переименовываются в `*.1`. Журнал действий пользователей — `audit.jsonl`, его видно на странице «Администрирование».
