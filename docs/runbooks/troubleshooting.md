# Ранбук: если что-то не работает

**Начните с диагностики:** `scripts\doctor.cmd` на домашнем компьютере. Она работает без портала, ничего не меняет и по каждому пункту говорит «ОК», «ВНИМАНИЕ» или «ОШИБКА» и что делать. У каждой функции есть запасной способ — [feature-fallback-matrix.md](../feature-fallback-matrix.md); ниже — частые случаи.

| Симптом | Что проверить | Как исправить |
|---|---|---|
| `scripts\start.cmd`: «Node.js не найден» | `"C:\FamilyServer\tools\nodejs\node.exe" -v` | установить Node.js 24 LTS в `C:\FamilyServer\tools\nodejs` (README → «Установка на новом ПК») |
| Файлы, установленные или созданные из Claude Desktop, «пропали» в Проводнике / портал не видит данных | лежат ли они в `%LOCALAPPDATA%` или `%APPDATA%` | из Claude Desktop такие записи уходят в виртуальную копию (`…\AppData\Local\Packages\Claude_pzs8sxrjxfjjc\LocalCache\`); всё серверное держать в `C:\FamilyServer` (`docs/environment-audit.md`, раздел 12) |
| «Порт 8070 уже занят» | `scripts\status.cmd` | остановить другой процесс или задать `PORT=…` в `.env` |
| «Сервер завершился при запуске» / «не ответил за 25 секунд» | скрипт печатает последние строки обоих журналов: `logs\dashboard.out.log` (ошибки запуска сервера, например занятый или зарезервированный Windows порт) и `logs\dashboard.err.log` (ошибки настроек) | исправить причину из журнала: другой `PORT`, корректный `HOST`, правильные значения в `.env`. Повреждённые JSON-файлы в каталоге данных сервер не останавливают — он пишет предупреждение в журнал и работает дальше |
| Скрипт пишет «Файл .env сохранён с BOM или в UTF-16» | `.env` создан командой `>` в PowerShell или сохранён «с BOM» | пересохранить `.env` в UTF-8 без BOM (Блокнот → «Сохранить как» → кодировка UTF-8) |
| В браузере «Интерфейс ещё не собран» | есть ли `dist\web\index.html` | `npm.cmd run build` |
| `npm` в PowerShell: «выполнение сценариев отключено» | политика выполнения `Restricted` | использовать `npm.cmd` (политику менять не нужно) |
| Телефон не открывает `https://server-home…ts.net` | Tailscale на телефоне включён? `scripts\status.cmd` показывает Serve? ПК включён и выполнен вход в Windows? | включить Tailscale на телефоне; `scripts\serve-tailnet.cmd`; войти в Windows |
| Страница входа: «Слишком много попыток» | — | подождать указанное время (15 мин окно) |
| Ответ 421 «Запрос отклонён: неизвестный адрес сервера» | портал открыт по имени/адресу, которого нет в настройках (защита от DNS-rebinding) | открывать по `http://127.0.0.1:8070`, адресу из `PUBLIC_URL` или `LAN_URL`; для нового адреса — добавить его в `.env` (`PUBLIC_URL`/`LAN_URL`) и перезапустить |
| Забыт пароль | — | администратор: «Администрирование» → «Пользователи» → «Управление» → «Выдать новый временный пароль» (показывается один раз). Если забыл администратор или портал не открывается: на сервере `scripts\user.cmd passwd <логин> --generate-password` |
| Ни один адрес портала не открывается | `scripts\doctor.cmd`: портал отвечает? программы работают? | `scripts\service.cmd restart dashboard`; если супервизор не работает — `scripts\start.cmd`; подробности в `logs\supervisor.log` |
| Дома пропал интернет, а портал нужен с телефона | включён ли запасной адрес: `scripts\lan-mode.cmd status` | если выключен — на ПК `scripts\lan-mode.cmd on` (от имени администратора), затем `http://<адрес ПК>:8070` в домашнем Wi‑Fi. Подробно — `network.md`, «Запасной адрес» |
| Jellyfin не открывается | `scripts\doctor.cmd`, «Кинотеатр» в портале | `scripts\service.cmd restart jellyfin`. Пока он не работает: «Кинотеатр» → «Запасной просмотр без Jellyfin» — файлы играют прямо из портала |
| Телефон не загружает фото | сообщение под кнопкой «Добавить фото и видео» | повторить по Wi‑Fi/Tailscale; запасной способ: подключить телефон кабелем, скопировать папку DCIM на ПК и `scripts\import.cmd <папка> --user <логин> --root photos` |
| Принтер выключен, а документ нужен | «Печать» пишет «Принтер сейчас не отвечает» | нажать «Напечатать, когда принтер включат» (документ напечатается сам, не позже чем через сутки) или скачать файл из «Файлов» и напечатать с самого ПК |
| Календарь или заметки: «файл повреждён» / ошибка 503 | `C:\FamilyServer\data\dashboard\calendar.json` | портал сам файл не перезаписывает. Восстановить из последней копии (`backup-restore.md`) или переименовать повреждённый файл — календарь начнётся пустым. Заметки — обычные .txt в «Файлы» → «Заметки» |
| Заметка: «только что изменил кто-то другой» | два человека правили одну заметку | скопировать свой текст, закрыть заметку, открыть заново и вставить; чужая правка не потеряна |
| Нет ни одного администратора | страница входа показывает команду | `scripts\user.cmd add <логин> --name "<Имя>" --role admin` |
| Сервис «Не отвечает» | открыть его адрес на сервере; `services.json` | запустить сервис; проверить `healthUrl` |
| «Ошибка в файле настроек сервисов» (видно администратору) | `C:\FamilyServer\data\dashboard\services.json` | исправить JSON (или удалить файл — создастся заново со значениями по умолчанию) |
| Состояние диска/принтера «Нет данных» | PowerShell-проба не успела за 15 с или Windows не отдала данные | подождать 5 минут (период опроса); проверить `Get-PhysicalDisk` вручную |
| Дашборд: резервное копирование — «ошибка», «флешка «reserve» — нет» | `C:\FamilyServer\data\dashboard\logs\backup.log`; подключена ли флешка с меткой `reserve` | вставить флешку и запустить `scripts\backup.cmd`; подробно — `backup-restore.md` → «Если флешка не подключена» |
| Резервная копия «устарела» или ночью не выполнилась | `Get-ScheduledTaskInfo -TaskName FamilyServerBackup` (`LastRunTime`, `LastTaskResult`) | задача работает только при выполненном входе в Windows; запустить `scripts\backup.cmd` вручную; если задачи нет — `scripts\backup-schedule.cmd` |
| `scripts\backup.cmd verify`: «Содержимое файла … изменено» / «Нет файла» | копия повреждена | не восстанавливать из неё; взять другую копию (`scripts\backup.cmd list`), сделать новую (`scripts\backup.cmd`) и проверить носитель |
| Замечание «Копия кода не создана» / «Git не найден» | `GIT_EXE` в `.env` | указать `C:\FamilyServer\tools\git\cmd\git.exe`; данные при этом всё равно копируются |

Диагностический отчёт без секретов: «Администрирование» → «Скачать диагностику».
