# Ранбук: люди, календарь, заметки, перенос файлов, диагностика

**Статус: Implemented** (17.10.2026). У каждой возможности есть запасной способ — [feature-fallback-matrix.md](../feature-fallback-matrix.md).

## Учётные записи

В портале: «Администрирование» → «Пользователи».

| Действие | Как | Что важно |
|---|---|---|
| Добавить человека | «Добавить человека»: логин, имя, роль, права | пароль не придумывается: портал создаёт **временный**, показывает его **один раз**; он действует 7 дней и только для первого входа, затем человек задаёт свой |
| Новый временный пароль | «Управление» → «Выдать новый временный пароль» | старый пароль и все открытые входы человека перестают работать; снимается блокировка «слишком много попыток» |
| Права | «Управление» → «Загрузки по ссылке» / «Печать» | у администратора все права |
| Роль | «Управление» → «Сделать администратором» / «обычным пользователем» | свою роль менять нельзя; последнего администратора разжаловать нельзя |
| Удалить | «Управление» → «Удалить» | личные файлы и фото **не удаляются**: папки человека переносятся в `C:\FamilyData\Files\.trash\removed-users\<логин>-<дата>` (и такую же в «Фото»), чтобы человек с тем же логином потом не получил чужое; вернуть их может администратор на сервере. Личные события календаря удаляются, общие остаются у семьи. Вход в Jellyfin отдельный — удаляется там |

Запасной путь, если портал не открывается — на самом компьютере: `scripts\user.cmd` (`add`, `list`, `passwd`, `role`, `allow`, `deny`, `remove`). Все действия попадают в журнал; паролей в журнале нет.

## Календарь и заметки

- **Календарь** (в «Ещё»): общие события семьи и личные («Только для меня» — не видит никто, даже администратор). Повтор: каждую неделю, месяц, год; можно на несколько дней. Менять и удалять событие может автор и администратор. На главной показываются события сегодня и завтра.
  - Данные: `C:\FamilyServer\data\dashboard\calendar.json` (входит в каждую резервную копию). Если файл повреждён, портал его не трогает и пишет об этом.
  - Запасной путь: «Скачать календарь (.ics)» — файл открывается в календаре телефона или ПК и остаётся у вас без портала.
  - 29–31 числа и 29 февраля: событие бывает только в тех месяцах и годах, где такая дата есть.
  - Лимит: 300 событий на человека (общий — 5000), чтобы один человек не заполнил календарь для всех. Если в месяце слишком много повторов, портал так и скажет.
- **Заметки**: короткий текст для семьи («Общие») или для себя («Мои»). Каждая заметка — обычный файл `.txt` в папке «Заметки» раздела «Файлы», поэтому она есть и в копиях, и в Проводнике на ПК. Если заметку изменил кто-то ещё (проверяется и время, и текст), сохранение отклоняется и ничего не теряется. Заметка — до 200 КБ текста.

## Перенос файлов и фото без браузера

Работает на самом компьютере, для существующей учётной записи. Исходная папка не меняется, программы не принимаются, место на диске не опускается ниже допустимого.

```bat
scripts\import.cmd D:\Фото-с-телефона --user mama --root photos
scripts\import.cmd D:\Документы --user mama --space shared --to Сканы
scripts\import.cmd D:\Документы --user mama --dry-run
scripts\export.cmd --user mama --to E:\Копия-файлов
```

- Фото раскладываются по месяцам по дате файла; принимаются только настоящие фото и видео. Миниатюры появятся, когда кто-нибудь откроет месяц в «Фото».
- Повторный запуск ничего не дублирует: файл с тем же именем и размером пропускается.
- `export` копирует в новую или пустую папку; корзина и временные файлы не берутся.
- Код выхода: 0 — всё хорошо, 3 — часть файлов не удалась, 1 — ошибка, 2 — неверная команда.

## Диагностика и ручное управление

| Команда | Зачем |
|---|---|
| `scripts\doctor.cmd` | независимая проверка без портала: портал, супервизор, Jellyfin, Tailscale, место, диски, копия, принтер, брандмауэр, UAC, где слушает портал. Только читает. Код выхода 0 — порядок, 1 — предупреждения, 2 — ошибки. `--json` — для программ |
| `scripts\status.cmd` | супервизор, адреса, автозапуск, Tailscale Serve |
| `scripts\service.cmd status` | состояние программ под супервизором |
| `scripts\service.cmd restart dashboard` | перезапустить портал (то же для `jellyfin`; есть `start` и `stop`) |
| `scripts\start.cmd` / `stop.cmd` | запустить всё, включая супервизор / остановить всё |
| `scripts\lan-mode.cmd` | запасной адрес в домашней сети: [network.md](network.md) |

## Локальный ИИ для «Оливии» (необязательно)

Не подключён и не нужен: правила «Оливии» объясняют всё измеряемое. Если владелец когда-нибудь установит сервер модели с интерфейсом, совместимым с OpenAI (Ollama, llama.cpp), в `.env`:

```
OLIVIA_LLM_URL=http://127.0.0.1:11434/v1
OLIVIA_LLM_MODEL=<имя модели>
```

Адрес принимается только на этом же компьютере. ИИ получает одну находку без адресов и папок, отвечает текстом (до 1200 знаков, очищается), ничего не выполняет, а ответ подписан как машинный. Подробности и оценка ресурсов — [ADR-0008](../decisions/0008-olivia-without-ai.md).
