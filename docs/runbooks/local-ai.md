## Установка

```bash
scripts\ai-setup.cmd
```

Скрипт покажет файл, источник и размер и спросит «да». Установит в `C:\FamilyServer\apps\llama` и `C:\FamilyServer\data\models`. Затем добавьте в `.env` (UTF-8 **без** BOM) строку:

```
OLIVIA_LLM_URL=http://127.0.0.1:8081/v1
```

и перезапустите портал:

```bash
scripts\service.cmd restart dashboard
```

Супервизор сам запустит программу `llama` (если есть и программа, и файл модели). Проверка: `scripts\service.cmd status` — строка `llama`; в портале «Оливия» показывает «Языковая модель работает на этом компьютере».

## Настройки в `.env` (все необязательны)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `OLIVIA_LLM_URL` | пусто (модели нет) | адрес **только на этом ПК** |
| `OLIVIA_LLM_MODEL` | `local` | подпись модели |
| `OLIVIA_LLM_TIMEOUT_SEC` | 90 | сколько ждать ответ |
| `OLIVIA_MODEL_FILE` | `C:\FamilyServer\data\models\qwen2.5-1.5b-instruct-q4_k_m.gguf` | файл модели |
| `OLIVIA_LLM_THREADS` | 3 | потоки процессора (1–16) |
| `OLIVIA_LLM_CONTEXT` | 2048 | длина контекста (512–8192) |
| `SUPERVISE_LLAMA` | включено | `0` — не запускать модель супервизором |

## Запуск, остановка, обновление, смена

- Статус/запуск/остановка: `scripts\service.cmd status|start|stop|restart llama`.
- Обновить программу: смените версию, размер и SHA-256 в `scripts\components.json`, остановите `scripts\service.cmd stop llama` и запустите `powershell -ExecutionPolicy Bypass -File scripts\install-component.ps1 -Name llama -Reinstall` (прежняя папка переименуется в `llama.old-<дата>`, не удаляется).
- Другая модель: положите `.gguf` в `C:\FamilyServer\data\models`, пропишите `OLIVIA_MODEL_FILE`, `service.cmd restart llama`. Для русского и JSON подходят Qwen2.5 1.5B/3B; модели больше 3B на этом ПК не рекомендуются.
- Выключить совсем: уберите `OLIVIA_LLM_URL` — модель не запускается, «Оливия» на правилах.

## Если не работает

| Симптом | Причина | Что делать |
|---|---|---|
| «Языковая модель не подключена» | `OLIVIA_LLM_URL` не задан | добавьте строку и перезапустите портал |
| «не отвечает» | модель ещё грузится (1–2 минуты после запуска) или программа упала | `service.cmd status`; журнал `llama.err.log` в папке журналов |
| Программа `llama` не появляется | нет `llama-server.exe` или файла модели, либо `SUPERVISE_LLAMA=0` | проверьте пути выше |
| Ответы странные | модель маленькая | это ожидаемо: итоговый ответ всё равно собирается из фактов; можно взять 3B |
