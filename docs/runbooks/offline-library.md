# Офлайн-библиотека, Plex и экстренная карточка

Статус на 02.11.2026: **код реализован, проверено автоматически и на тестовом портале (страницы открываются, Plex показывает настоящие библиотеки); Википедия ещё докачивается — проверка поиска по ней впереди.**

## Офлайн-библиотека (Википедия без интернета)

Зачем: если надолго пропадёт интернет (авария, война, обрыв кабеля), семья сможет искать в заранее скачанной Википедии с телефона или телевизора, пока работают сервер и домашняя сеть.

- **Что стоит.** Kiwix-serve 3.8.1 (официальная сборка kiwix.org; MD5 с сайта совпал) в `C:\FamilyServer\apps\kiwix`. Книги (файлы `.zim`) — в `D:\FamilyData\OfflineLibrary`: Википедия на русском **с картинками** (34,6 ГБ), на белорусском (без картинок), Викисловарь, Викигид (путешествия), Викиучебник на русском. Английскую (49 ГБ без картинок) и другие можно добавить: положите `.zim` с download.kiwix.org в ту же папку.
- **Как запускается.** Программа `kiwix` под супервизором, слушает только `127.0.0.1:8089`; портал пускает к ней вошедших людей по адресу `/offline/` (тот же вход, тот же Tailscale). Список книг читается при запуске, поэтому после добавления книги нажмите «Перезапустить» у «Офлайн-библиотека (Kiwix)» на странице «Сервер». Недокачанные книги (рядом файл `.aria2`) не подключаются.
- **Где искать в портале.** «Память» → «Офлайн-библиотека»: строка поиска и выбор книги, кнопка «Открыть всю библиотеку».
- **Докачка.** Загрузка идёт программой aria2 (с продолжением при обрыве); если остановилась, запустите ещё раз команду из `D:\FamilyData\OfflineLibrary\_urls.txt`: `aria2c -c -x4 -d <папка> -i _urls.txt`.
- **Честно.** Это копия на дату скачивания. Без интернета Оливия сама пока **не** ищет в офлайн-библиотеке (её поиск — SearXNG и новости из сети); это следующий шаг.

## Plex рядом с Jellyfin

Plex Media Server 1.43.5 привязан к вашему аккаунту, шесть библиотек созданы. В портале: «Медиа» → **«Plex (ТВ)»** — состояние, список библиотек с числом записей (читается с самого сервера, ключ входа не покидает ПК), адрес для телевизора, пошаговая инструкция для Samsung и сравнение с Jellyfin; ссылка на странице «Кинотеатр»; плитка «Медиа» на главной; подсказки; сервис «Plex (для телевизора)» в списке сервисов. Plex — внешняя программа Windows (не под супервизором): если его нет, страница так и скажет. Плагинов у Plex больше нет (их система закрыта самим Plex): субтитры включаются в настройках библиотеки.

## Экстренная карточка

«Память» → «Экстренная карточка»: телефоны служб Беларуси (112, 101, 102, 103, 104) и заготовки разделов: наши телефоны, где встречаться, документы, здоровье, тревожный набор. Пишет администратор (строка «# Заголовок» начинает раздел), читают все. Телефон хранит последнюю копию и покажет её, даже если сервер не ответит; страница печатается без меню. Лежит в `data\dashboard\emergency.json` и попадает в копии.

## Недельный отчёт

По воскресеньям после 19:00 администраторы с привязанным Telegram получают отчёт о сервере (картинка и PDF): так медленные проблемы видны заранее. Выключить: «Администрирование» → «Функции» → «Отчёты Оливии».
