# Docker (ArchiveBox, Home Assistant)

Статус: **требует настройки владельцем**. На этом ПК WSL и Docker не установлены (проверено 02.11.2026: `wsl --status` показывает только справку, компонентов нет). Установка требует прав администратора и перезагрузки, поэтому она не выполнялась автоматически.

## Что даёт Docker
- **ArchiveBox** — полноценный архиватор страниц. Сейчас «Сохранённые страницы» работают без него (свой сохранитель + поиск), Docker нужен только для расширенных форматов.
- **Home Assistant** — умный дом. Нужен, только если в доме есть совместимые устройства.

## Установка (один раз)
1. ПКМ по «Пуск» → «Windows PowerShell (администратор)».
2. `cd "C:\Users\PC\Desktop\THE DASHBOARD"` и `powershell -ExecutionPolicy Bypass -File scripts\install-docker.ps1`
3. Перезагрузить ПК, один раз открыть Docker Desktop и принять условия.
4. `docker compose -f deploy\docker\compose.yml --profile archivebox up -d` (адрес только на этом ПК: http://127.0.0.1:8100).

Цена: Docker Desktop с WSL2 держит около 1–2 ГБ ОЗУ; на ПК 16 ГБ, из них часть занимает большая модель Оливии. Поэтому контейнеры запускаются по профилям, а не все сразу.

Файловые данные лежат на `D:\FamilyData\ArchiveBox` и `D:\FamilyData\HomeAssistant`. Порты открыты только на 127.0.0.1; в семью их выдаёт портал.
