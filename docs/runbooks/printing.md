# Ранбук: печать из портала

**Статус: Implemented** (17.10.2026). Решение — [ADR-0009](../decisions/0009-printing.md).

## Для семьи

1. «Ещё» → «Печать».
2. Выберите PDF или JPG, число копий, стороны и цвет.
3. Нажмите «Проверить на принтере».
4. После «Принтер проверил задание» нажмите «Напечатать». Статус меняется: «Отправлено» → «Печатается» → «Напечатано». Пока не напечатано, задание можно отменить.

Word и Excel сначала сохраните как PDF («Файл» → «Сохранить как» → PDF). Если вы не дома, лист будет ждать в лотке принтера.

## Для администратора

| Что | Как |
|---|---|
| Разрешить печать человеку | `scripts\user.cmd allow <логин> print` (забрать — `deny`) |
| Адрес принтера | `.env`: `PRINTER_IPP_URL=https://192.168.1.139/ipp/print`; после изменения — `scripts\stop.cmd` и `scripts\start.cmd` |
| Лимит размера файла | `.env`: `PRINT_MAX_MB=30` |
| Журнал | «Администрирование» → журнал: «Отправлено на печать», «Печать отменена», «Печать не удалась» |
| Временные файлы | `C:\FamilyServer\data\dashboard\print-spool` — удаляются сами, когда задание закрыто |

**Закрепите IP принтера в роутере** (резервирование DHCP для MAC `50-C2-E8-06-A0-CD`). Если адрес сменился:
1. Узнать новый: в PowerShell `Resolve-DnsName NPID6ECE2.local`.
2. Прописать его в `PRINTER_IPP_URL`.
3. Перезапустить портал.

## Неполадки

| Симптом | Что делать |
|---|---|
| «Не отвечает» | принтер включён и в сети? Не сменился ли IP (см. выше)? |
| «Принтер прервал печать» | замятие или нет бумаги — посмотрите на экран принтера. Если бумага есть, а прерывается всё: печатает ли принтер через Windows («Печать пробной страницы»)? |
| «Принтер не поддерживает этот формат» | сохраните файл как PDF |
| «Файл защищён паролем» | снимите защиту в программе просмотра и сохраните заново |
| Нет кнопки печати у родственника | выдайте право: `scripts\user.cmd allow <логин> print` |
