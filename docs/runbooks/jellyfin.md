# Ранбук: кинотеатр (Jellyfin)

**Статус: Implemented** (17.10.2026). Решение и замеры — [ADR-0005](../decisions/0005-jellyfin.md).

| Что | Где |
|---|---|
| Адрес для семьи (телефон, ноутбук, этот ПК) | **https://server-home.tail89d77e.ts.net:8443** — только при включённом Tailscale |
| Адрес на самом ПК | http://127.0.0.1:8096 |
| Программа | `C:\FamilyServer\apps\jellyfin` (Jellyfin 12.2, официальный ZIP) |
| Данные и настройки Jellyfin | `C:\FamilyServer\data\jellyfin` (`config`, `data`, `cache`, `log`) |
| Фильмы | `C:\FamilyData\Media\Фильмы`, `Сериалы`, `Мультфильмы`, `Домашнее видео`, `Музыка`, `Аудиокниги` |
| Ключ API для супервизора | `C:\FamilyServer\data\dashboard\jellyfin-api.json` (секрет, не в Git) |
| Запуск, остановка | супервизор: `scripts\start.cmd` / `scripts\stop.cmd`; только Jellyfin — `…\supervisor\main.ts restart jellyfin` (см. `start-stop.md`) |

## Первый вход и пользователи

1. Владелец входит в Jellyfin под `alex` с паролем из итогового сообщения настройки.
2. Сразу меняет пароль: значок профиля → «Профиль» → «Пароль».
3. Для каждого родственника создаёт пользователя: «Панель управления» → «Пользователи» → «+».
   - Без прав администратора.
   - «Разрешить удалённые подключения» оставить включённым: через tailnet человек подключается как «локальный», но настройка не мешает.
   - Доступ — к нужным библиотекам. Для детей можно ограничить возрастной рейтинг.

Повторная автоматическая настройка безопасна и ничего не ломает: `scripts\jellyfin-setup.cmd`. Она добавит недостающие библиотеки и ключ API.

## Аудиокниги

Библиотека «Аудиокниги» (тип «Книги») смотрит в `C:\FamilyData\Media\Аудиокниги`. Одна книга — одна папка, одна глава — один файл: `Аудиокниги\Название книги\Глава 01.mp3`. Проверено 17.10.2026: Jellyfin видит такие файлы как `AudioBook`. В папке лежит тестовая «Тестовая аудиокнига (2026)» из двух синтезированных нот — её можно удалить. Приложение Jellyfin на телефоне запоминает место остановки.

Библиотека создаётся командой `scripts\jellyfin-setup.cmd` (она безопасна при повторном запуске и добавляет только недостающее).

## Если Jellyfin не работает: запасной просмотр

«Кинотеатр» → «Запасной просмотр без Jellyfin» (открывается сам, когда Jellyfin не отвечает). Портал отдаёт файлы из `C:\FamilyData\Media` прямо браузеру: фильмы, музыка, аудиокниги, с перемоткой. Для аудио место остановки запоминается на этом устройстве.

Что он **не** умеет: перекодировать (тяжёлый HEVC/4K на телефоне может не играть), субтитры, обложки и описания, разные профили просмотра. Каждый вошедший видит весь каталог — как в Jellyfin по умолчанию. Это запасной путь, а не замена.

## Как добавить фильм

Скопируйте файл в нужную папку, например `C:\FamilyData\Media\Фильмы\Название (Год)\Название (Год).mkv`. Jellyfin заметит его сам: в библиотеках включено слежение за папками. Обновить вручную: «Панель управления» → «Библиотеки» → «Сканировать все библиотеки».

Только законные файлы: свои записи, купленные без DRM, свободные. Автоматическое скачивание фильмов не настроено и не будет.

## Где смотреть

| Устройство | Как |
|---|---|
| Телефон (iOS/Android) | приложение **Jellyfin** из App Store / Google Play → сервер `https://server-home.tail89d77e.ts.net:8443`. Tailscale на телефоне должен быть включён. Или в браузере по тому же адресу |
| Этот ПК и телевизор по HDMI | браузер на ПК → `http://127.0.0.1:8096` или кнопка «Кинотеатр» в портале |
| Samsung QN800B напрямую | **не проверено**. У телевизора нет Tailscale, а Jellyfin не открыт в домашнюю сеть. Варианты: HDMI от ПК (работает уже сейчас) или, по решению владельца, LAN-доступ (правило брандмауэра) и приложение Jellyfin для Tizen |

## Проверено 17.10.2026

| Проверка | Результат |
|---|---|
| Jellyfin слушает | только `127.0.0.1:8096` (TCP); UDP 7359 не открыт |
| `https://…:8443/health` из tailnet | 200 `Healthy`, сертификат валиден |
| `http://192.168.1.252:8096`, `http://100.116.219.8:8096` | нет соединения |
| Воспроизведение в Chrome (тестовое 1080p) | DirectPlay, 0 потерянных кадров, Jellyfin 0,39 % CPU |
| Перекодирование для слабого канала | NVENC, 7,6× реального времени |
| `restart jellyfin` через супервизор | Jellyfin завершился сам (код 0) за ~15 с, через 20 с снова `Healthy` |
| Принудительное завершение jellyfin.exe | супервизор перезапустил через 1 с, `Healthy` через 8 с |
| Карточка «Кинотеатр» в портале | «Работает» со ссылкой на `:8443`; при остановке — «Остановлен» с подсказкой |

**Ручные проверки владельца:**
- воспроизведение на телефоне вне дома — через мобильный интернет, с включённым Tailscale;
- воспроизведение на телевизоре через HDMI;
- реальная скорость домашнего интернета на отдачу: от неё зависит качество вне дома. При 10 Мбит/с и ниже ставьте в клиенте «Качество» 4–8 Мбит/с — тогда сработает перекодирование на NVENC.

## Обновление Jellyfin

1. Скачать новый ZIP с https://repo.jellyfin.org/?path=/server/windows/latest-stable и сверить SHA-256: страница файла → `?sha256`.
2. `scripts\stop.cmd`
3. Переименовать `C:\FamilyServer\apps\jellyfin` в `jellyfin.old`, распаковать новую версию в `C:\FamilyServer\apps\jellyfin`.
4. `scripts\start.cmd`, затем открыть Jellyfin и проверить воспроизведение. Если всё в порядке, удалить `jellyfin.old`.

Перед обновлением сделайте копию: `scripts\backup.cmd`. Конфигурация и база Jellyfin входят в копию с этапа P5.

## Неполадки

| Симптом | Что сделать |
|---|---|
| Портал: «Кинотеатр — Остановлен» | `scripts\start.cmd` или `…\supervisor\main.ts start jellyfin` |
| «Сбой: перезапускается» долго не проходит | `C:\FamilyServer\data\dashboard\logs\supervisor.log` и `jellyfin.err.log`, логи Jellyfin — `C:\FamilyServer\data\jellyfin\log` |
| Не открывается `https://…:8443` | на устройстве включён Tailscale? `tailscale serve status` на ПК должен показывать `:8443 → 127.0.0.1:8096`; включить — `scripts\serve-tailnet.cmd -Jellyfin` |
| Видео тормозит вне дома | в клиенте снизить «Качество» (4–8 Мбит/с) |
| Забыт пароль администратора Jellyfin | на странице входа Jellyfin «Напомнить пароль»: Jellyfin запишет PIN-файл в `C:\FamilyServer\data\jellyfin\config` (виден только на ПК), по нему сбросить пароль |
