## 7. Чего нет / что неизвестно

- SMART-атрибуты дисков: штатными средствами Windows без админ-прав доступен только `HealthStatus` (Healthy). Детальный SMART требует smartmontools (не устанавливался).
- Температурные датчики CPU/GPU/дисков: поддерживаемого источника без драйверов/админ-прав нет → на дашборде «нет данных», а не выдуманное значение.
- Уровни тонера HP M283fdw: драйвер IPP Class Driver их не отдаёт через `Get-Printer` → не показываются.
- Samsung QN800B: в сети с этого ПК не проверялся (не нужен для MVP).
- Реальная пропускная способность домашнего интернета (upload) не измерялась.

## 8. Риски

1. **Один физический диск** — нет избыточности, бэкап на том же диске не спасает от отказа.
2. **Неисправное/заблокированное второе устройство** — требуется проверка пользователем (кабели, BIOS, SMART), см. раздел 9.
3. **Windows 10 Home без текущих обновлений безопасности** — поэтому никакой публикации в интернет, только loopback + tailnet.
4. **Сторонний VPN (PlanetVPN/xray)** может влиять на маршрутизацию; Tailscale при этом работает (`Running`).
5. Нет Docker/WSL2 → сервисы вроде Immich (официально Docker-only) на этой машине потребуют отдельного решения.

### Второй диск `ST_M13FQBL` (3,9 ГБ)

- Seagate официально это обозначение не документирует. По многочисленным отчётам сообществ восстановления данных (HDDGuru 2009–2026, MSFN, SevenForums) модель `ST_M13FQBL`, серийный `QNR_BFW` и ёмкость 8 089 950 секторов (= 4 142 054 400 байт — ровно то, что видит Windows) — это **заглушка, которую выдаёт накопитель Seagate, когда контроллер не смог загрузить прошивку с пластин** (сбой платы/ПЗУ, служебной зоны, головок или мотора; реже — кабель или питание).
- Вывод (с высокой вероятностью, не проверено физически): это и есть ожидаемый второй диск 2 ТБ в неисправном состоянии. Windows при этом показывает `HealthStatus=Healthy`, поэтому дашборд помечает такой диск предупреждением по эвристике.
- **Что можно сделать (пользователю, при выключенном ПК):** переподключить SATA-кабель и питание, попробовать другой порт; посмотреть модель в BIOS. Если щёлкает или циклично раскручивается — выключить и не включать. Если на диске важные данные — не пытаться «чинить» прошивку и не менять плату, а обращаться в лабораторию восстановления.
- **Нельзя:** нажимать «Инициализировать» в «Управлении дисками», `Initialize-Disk`, `diskpart clean`, форматирование, `chkdsk`, прошивки/«Fix All» в SeaTools.
- smartmontools 7.5 для read-only проверки требует установщика с правами администратора (UAC) — **не устанавливался**; на диске в таком состоянии SMART, скорее всего, не прочитается.

### Tailscale

- Клиент **1.104.1** — актуальная стабильная версия на 07.10.2026.
- `tailscale serve --bg --https=443 http://127.0.0.1:PORT` даёт HTTPS **только внутри tailnet**, для проксирования порта права администратора не нужны, настройка сохраняется после перезагрузки ([KB 1242](https://tailscale.com/kb/1242/tailscale-serve), [KB 1312](https://tailscale.com/kb/1312/serve)). Funnel — отдельная публичная функция, проект её не включает.
- Включённые HTTPS-сертификаты публикуют имя `server-home.tail89d77e.ts.net` в публичных журналах Certificate Transparency (доступа это не даёт; имя нейтральное).
- По умолчанию Tailscale на Windows работает в сессии пользователя: **после перезагрузки до входа в Windows удалённого доступа нет**, если не включён режим Unattended (решение пользователя).
- Serve добавляет `X-Forwarded-For/Host/Proto` и заголовки личности `Tailscale-User-*` (кодировка RFC 2047 для кириллицы); доверять им можно только при подключении с loopback.
