# Публичные и приватные документы

Репозиторий публичный, поэтому в нём нет ничего, что нужно только владельцу этого сервера: настоящего имени узла Tailscale, адресов домашней сети, имён устройств и родственников, подробного описания железа, паролей и ключей. Вместо них в документах стоят заполнители (`server-home.example.ts.net`, `192.168.1.20`, «администратор»).

## Где настоящие значения

| Что | Где лежит | В Git |
|---|---|---|
| Адрес портала в tailnet, адрес принтера, пути к данным | локальный `.env` в папке проекта | нет (`.gitignore`) |
| Пароли, ключи API, секреты RPC, VAPID-ключи, ключ шифрования копий | папка данных `C:\FamilyServer\data\dashboard` и `C:\FamilyServer\secrets` | нет |
| Подробные инструкции владельца, журнал проверок, описание железа | папка `docs/private/` (создаётся владельцем, пример имён ниже) | нет (`.gitignore`) |

Рекомендуемые файлы в `docs/private/`: `owner-actions.md` (настоящие шаги с именами устройств), `environment-audit.md`, `EXECUTION_EVIDENCE.md`. Публичные версии этих файлов лежат рядом в `docs/` и содержат только общее. Файлы из `docs/private/` попадают в резервные копии (как «дополнительные файлы» рядом с `.env`), но не в GitHub.

## Что не должно попадать в публичный репозиторий

Секреты и токены; адреса и имена из домашней сети; имена устройств и людей; серийные номера и фрагменты MAC-адресов; снимки экрана с реальными данными. Снимки для руководства делаются на тестовом сервере (`npm run guide:screenshots`), а на снимке «Состояние» перед съёмкой закрашиваются имя в сети, имя компьютера, имя принтера и названия сетевых адаптеров.

## Копия кода на GitHub

Ежедневная копия отправляет на GitHub только то, что **закоммичено** в ветку `main` (`git push`, только fast-forward, только на `https://github.com/…`); рабочие файлы, `.env`, `docs/private/` и данные семьи туда не попадают. Перед первой публикацией новых файлов проверяйте `git status`.

## Что уже в истории Git

Раньше в историю попали и остаются там: имя узла Tailscale, адреса домашней сети, имя принтера с фрагментом MAC-адреса, имя стороннего VPN-адаптера, имена родственников и логин администратора, старые снимки экрана «Состояние». Секретов (паролей, токенов, ключей) в истории нет — проверено сканированием всех коммитов. Переписывать историю без отдельного решения владельца нельзя; если нужно скрыть и это, придётся пересоздавать репозиторий или чистить историю инструментом вроде `git filter-repo` — решение владельца.
