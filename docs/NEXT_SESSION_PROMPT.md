## Как работать на этом ПК (важно)

- **PATH сессии Claude Desktop** указывает на старый Node в AppData, который падает. Всегда ставь первым `C:\FamilyServer\tools\nodejs`:
  - PowerShell: `$env:Path = (@('C:\FamilyServer\tools\nodejs','C:\FamilyServer\tools\git\cmd') + @(($env:Path -split ';') | ? { $_ -and $_ -notmatch 'AppData\\Local\\Programs\\(nodejs|Git)' })) -join ';'` — массив обязательно в `@()`, иначе PATH склеится через пробелы;
  - bash: `export PATH="/c/FamilyServer/tools/nodejs:$PATH"`.
- **Проверки:** `npm.cmd run check`; `openspec.cmd validate --all --strict` (`OPENSPEC_TELEMETRY=0`); `npm.cmd audit`.
- **Портал и Jellyfin** работают под супервизором.
  - Применить новый код сервера: `node --env-file-if-exists=.env server\src\supervisor\main.ts restart dashboard`.
  - Состояние: `scripts\status.cmd`.
- **Обратные слэши.** Правки файлов с `\` делай инструментом Edit/Write, а не через `node -e` с шаблонными строками: `\u…` ломает разбор.
- **Сообщение коммита** пиши в файл и коммить `git commit -F <файл>`. Автор — noreply GitHub, пуш — `git push origin main`.
- **Проверки на рабочем портале** делай через временные учётки (`user.cmd add p?check … --password-stdin`) и удаляй их после проверки.
