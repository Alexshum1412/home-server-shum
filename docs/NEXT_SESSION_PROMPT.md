## Как работать на этом ПК

- **Node.** PATH сессии Claude Desktop может указывать на старый Node в AppData; всегда первым ставь `C:\FamilyServer\tools\nodejs`. Из Git Bash `npx.cmd` иногда падает: запускай из PowerShell и вызывай инструменты напрямую:
  ```powershell
  $env:Path = 'C:\FamilyServer\tools\nodejs;' + $env:Path
  node node_modules\vitest\vitest.mjs run
  node node_modules\typescript\bin\tsc -p tsconfig.json --noEmit
  node node_modules\typescript\bin\tsc -p web/tsconfig.json --noEmit
  node node_modules\typescript\bin\tsc -p tsconfig.e2e.json --noEmit
  node node_modules\@biomejs\biome\bin\biome check --write .
  ```
- **Браузерные тесты** идут на копии Chrome: `$env:E2E_CHROME = 'C:\FamilyServer\tools\chrome-copy\chrome.exe'`, затем `node node_modules\@playwright\test\cli.js test <файл> --project=real|chat|calls|demo|cinema`. Установленный Chrome падает при запуске (см. выше). Не обрывай раннер конвейером `| Select -First N`: тестовые серверы на портах 8071–8074, 8097, 8098 останутся занятыми (освободи их по порту; живой портал 8070 не трогай).
- **Картинки руководства:** `npm.cmd run build`, затем `node node_modules\@playwright\test\cli.js test -c playwright.guide.config.ts` (с `E2E_CHROME`). Люди на снимках выдуманные; в «Состоянии» закрашиваются имя компьютера, имя в tailnet, принтер, адаптеры и модели дисков — проверь снимки глазами.
- **Проверки:** `npm.cmd run lint`, `typecheck`, `test`, `build`, `test:e2e`; `openspec.cmd validate --all --strict` (`OPENSPEC_TELEMETRY=0`); `npm.cmd audit`.
- **Применить новый код на живом портале:** `npm.cmd run build`, затем `scripts\restart.cmd` (перезапускает программы супервизора; Windows не трогает). Состояние: `scripts\status.cmd`.
- **Правки файлов с обратными слэшами и обратными кавычками** делай инструментами Edit/Write, а не через `node -e` или `heredoc`: `\\`, `\d`, `` ` `` теряются или раскрываются; в PowerShell строки в двойных кавычках раскрывают `` `r ``, `` `a `` и `$` — используй here-string с одинарными кавычками. В `.ps1` с кириллицей — UTF-8 **с BOM**, в `.cmd` — только ASCII.
- **Проверки на рабочем портале** — через временные учётки (`scripts\user.cmd add <логин> --role admin --password-stdin`), пароль не печатать, учётку потом удалить.
- **Коммиты:** сообщение коммита пиши в файл или here-string; пуш — `git push origin main` (репозиторий публичный: только код и документация, секретов нет, настоящих имён и адресов нет — они в `docs/private/`).

- Не отключай защиту ради тестов; не исполняй команды, сформированные ИИ; не включай публичный доступ и Funnel; не клади семейные данные, пароли и токены в Git.
- Не переписывай Git-историю принудительно; не удаляй незакоммиченные пользовательские изменения.
- Не инициализируй, не форматируй и не используй диск `ST_M13FQBL` для данных или резервов; не меняй Firewall, Defender, UAC, обновления Windows, ACL/DNS/маршруты Tailscale; не пробрасывай порты; не удаляй и не переноси пользовательские данные.
- Не создавай много независимых ревьюеров и бесконечные циклы перепроверки: один аудит, одна правка.
- Скачивание любого файла — только с явного согласия владельца в чате (имя, источник, размер) и с проверкой SHA-256; собственная сумма — не доказательство подлинности.
- Не заявляй готовность того, что не проверено.
