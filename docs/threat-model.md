# Модель угроз

**Статус:** этап P9, 17.10.2026. Краткая таблица рисков и мер — в [security.md](security.md); здесь — кто, откуда и через какую границу может навредить, что этому мешает и что остаётся.

## Что защищаем

| Актив | Где | Чем плох ущерб |
|---|---|---|
| Семейные файлы и фото | `C:\FamilyData\Files`, `C:\FamilyData\Photos`, копии на `C:` и флешке | личная жизнь семьи; потеря незаменима |
| Учётные записи портала | `C:\FamilyServer\data\dashboard\users.json` (хэши scrypt), `sessions.json` (SHA-256 токенов) | вход от имени члена семьи или администратора |
| Учётные записи и ключ API Jellyfin | `C:\FamilyServer\data\jellyfin` | управление кинотеатром |
| Сам ПК | Windows 10, пользователь `PC` — администратор, UAC выключен | процесс портала работает с полным токеном администратора: взлом портала = взлом ПК |
| Доступность | один ПК, один исправный диск | кино, файлы и копии недоступны |
| Принтер | HP M283fdw, `192.168.1.139` | бумага и тонер, напечатанные чужие документы |

## Кто может навредить

1. **Чужой человек в интернете.** Входящих соединений нет: нет проброса портов и Funnel, сервисы слушают `127.0.0.1`. Остаются исходящие пути: загрузки по ссылке и ответы серверов.
2. **Украденный или потерянный телефон семьи** с включённым Tailscale: видит страницу входа портала и Jellyfin.
3. **Член семьи (роль family)**, который пробует функции администратора или чужие файлы.
4. **Вредный сайт**, открытый на устройстве семьи: CSRF, DNS-rebinding, попытки читать API.
5. **Вредный файл**: загружен в «Файлы» или «Фото», скачан по ссылке, отправлен на печать.
6. **Гость в домашней сети (Wi-Fi или кабель).** Портал и Jellyfin в LAN не слушают. Но брандмауэр профиля «Частная сеть» сейчас **выключен** (ниже), поэтому гостю открыты службы Windows.
7. **Вредоносная программа на самом ПК.** Вне модели: при выключенном UAC защититься от неё портал не может. Мера — Defender (включён) и обновления.
8. **Отказы:** диск, флешка, питание, нехватка места, зависание программ.

## Границы доверия

```
 Интернет ──(только исходящие: загрузки, GitHub, обновления)──┐
                                                               │
 Телефон/ноутбук семьи ──Tailscale (WireGuard)──► tailscaled ─┤ Serve: HTTPS, только tailnet
                                                               ▼
                       ┌──────── ПК (Windows 10, пользователь PC, полный токен) ─────────┐
                       │ 127.0.0.1:8070  портал (Fastify) ──► файлы семьи, данные портала │
                       │       │ named pipe ▲                 PowerShell-пробы (allowlist)│
                       │       ▼            │                                             │
                       │  супервизор ──► 127.0.0.1:8096 Jellyfin                           │
                       └───────┬───────────────────────────────┬──────────────────────────┘
                               │ ipps (фиксированный IP)       │ копии
                               ▼                               ▼
                         принтер в LAN               C:\FamilyServer\backups, флешка «reserve»,
                                                     GitHub (только код, публичный)
```

### Г1. Tailnet → портал и Jellyfin (Tailscale Serve)

| Угроза | Мера | Остаток |
|---|---|---|
| Вход без пароля | все API, кроме входа и `/api/health`, требуют сессию; временный пароль — до смены, 7 дней | — |
| Подбор пароля | 10 неудач на имя / 30 на адрес за 15 мин → 429, scrypt | медленный подбор слабого пароля; политика ≥ 10 символов. **Принятый риск:** тот, кто достучался до страницы входа (устройство tailnet, гость домашней сети при включённом запасном адресе), может 15 минут держать закрытым вход конкретного человека, подобрав 10 неверных паролей; уже открытые сеансы это не затрагивает, а «Выдать новый временный пароль» снимает блокировку |
| Журнал входов | в журнал попадает логин только существующей учётной записи (пароль, набранный в поле логина, не записывается) | — |
| Администратор | видит и меняет людей, но не читает личное через интерфейс | администратор может выдать новый пароль и войти как человек: действие в журнале, у человека пропадает вход |
| Cookie сеанса и Jellyfin | cookie привязана к имени хоста, не к порту: браузер шлёт её и на `:8443` (Jellyfin) через тот же Serve | если бы Jellyfin раскрыл заголовки запросов, это показало бы сеансы портала; принято, пока Jellyfin доступен только своим устройствам; смена пароля завершает сеансы |
| Доступ к функциям администратора | `requireAdmin` на сервере; family не получает технических данных (IP, модели дисков, пути) | — |
| Права `downloads`/`print` | проверяются на сервере в каждом маршруте | — |
| Потоки Jellyfin без входа | известная особенность Jellyfin: поток по ID элемента. Доступен только из tailnet | принят: в tailnet только устройства семьи |
| Подмена `Host` / `X-Forwarded-*` | allowlist имён → 421; `X-Forwarded-For` учитывается только от loopback-прокси | — |

### Г2. Браузер (вредный сайт на устройстве семьи) → портал

| Угроза | Мера |
|---|---|
| CSRF | `SameSite=Strict`; изменяющие запросы только со своим `Origin`; `Sec-Fetch-Site: cross-site` → 403; JSON или `X-Upload: 1` у загрузок (кросс-сайтовый запрос без CORS не может поставить заголовок) |
| DNS-rebinding | allowlist `Host` |
| XSS | Preact экранирует; нет `innerHTML`; CSP `script-src 'self'`; пользовательские файлы показываются inline только безопасных типов и с `CSP: sandbox` |
| Clickjacking | `frame-ancestors 'none'` |

### Г3. Портал → операционная система

| Угроза | Мера | Остаток |
|---|---|---|
| Выполнение команд из запроса | нет shell и `eval`; PowerShell-пробы — фиксированные команды без пользовательских аргументов; программы супервизора и их аргументы заданы в коде | — |
| Выход за папку семьи | путь строится из сессии и проверяется по частям и через `realpath`; junction и ссылки отклоняются; зарезервированные имена Windows запрещены | — |
| Запуск загруженного | сервер не открывает файлы; программы не принимаются в «Фото» и при печати; на скачанных — Mark of the Web | — |
| Управление супервизором | именованный канал только на этом ПК | см. результаты ревью P9 |
| Действия «Оливии» | 4 действия из allowlist, только администратор, подтверждение, пауза 30 с, журнал | — |
| Полный токен администратора | **не устраняется проектом**: UAC выключен в Windows | рекомендация владельцу: включить UAC или запускать портал от отдельной учётной записи без прав администратора |

### Г3а. Новые возможности (P8–P10, 17.10.2026)

| Угроза | Мера | Остаток |
|---|---|---|
| Управление людьми из браузера | только администратор; пароль только генерируется и показывается один раз; нельзя удалить или разжаловать себя и последнего администратора; журнал без паролей | украденный сеанс администратора может завести учётную запись — поэтому смена пароля завершает все сеансы, а действия видны в журнале |
| Запасной адрес в домашней сети | выключен по умолчанию; частный адрес, не `0.0.0.0`; правило брандмауэра только для «Частной сети» и подсети; `Host`/`Origin` как везде | обычный HTTP: пароль идёт по домашней сети открытым текстом; гость сети может вести подбор (ограничен: 10 на имя / 30 на адрес за 15 мин) |
| Запасной просмотр кино | только чтение медиатеки, только аудио/видео, `CSP: sandbox`, проверка пути и ссылок | каждый вошедший видит весь каталог (как в Jellyfin) |
| Календарь и заметки | личное видит только автор (администратор тоже не видит); заметки — файлы с проверкой пути; конфликт правок не затирает чужую | нет шифрования на диске (как у всех файлов семьи) |
| Очередь печати | не печатает без явного выбора; документ хранится ≤ 24 ч; печатает только PDF/JPEG | сохранённый документ лежит на диске сервера открыто, пока не напечатан |
| `import`/`export` | только на самом ПК; те же запреты, что у загрузки (программы, подделка под фото); исходное не удаляется | кто сидит за ПК, тот может скопировать семейные файлы — это граница доверия «человек у компьютера» |
| Локальный ИИ «Оливии» | выключен; только адрес на этом ПК; одна находка без адресов и папок на входе; ответ — очищенный текст, действий не запускает | ИИ может ошибиться — ответ подписан как машинный |

### Г4. Портал → интернет (загрузки)

SSRF: соединение только с публичными адресами, проверка в DNS-lookup самого сокета и на каждом перенаправлении, только `http(s)`; лимиты размера и свободного места; программы не сохраняются ([ADR-0006](decisions/0006-downloads.md)).

### Г5. Портал → принтер в LAN

Адрес принтера — только из `.env`, не из запроса. Передача по `ipps`; сертификат принтера самоподписанный, поэтому не проверяется. Подмена принтера в LAN дала бы чужому прочитать отправленный документ: это риск LAN, а не портала. Сервер документ не разбирает ([ADR-0009](decisions/0009-printing.md)).

### Г6. Копии → флешка и GitHub

| Угроза | Мера | Остаток |
|---|---|---|
| Потеря флешки | — | **копии не зашифрованы**: на флешке семейные фото, хэши паролей, данные Jellyfin. Решение владельца — шифрование (BitLocker To Go) или хранение флешки дома |
| Порча копии | SHA-256 каждого файла, `verify`, `test-restore` | неизменённые файлы — жёсткие ссылки на одну копию; при порче одной копии портятся все версии файла |
| Утечка через GitHub | в GitHub только код; данные, `.env`, логи — в `.gitignore`; проверка истории на секреты — в P9 | — |

### Г7. Домашняя сеть → ПК

| Факт (проверено только чтением 17.10.2026) | Значение |
|---|---|
| Брандмауэр Windows: 17.10.2026 утром профиль «Частная сеть» был **выключен** (через «Безопасность Windows»), вечером **включён для всех трёх профилей** (проверено только чтением). Аудит P0 (15.10) тоже показывал все профили включёнными; ни одна команда проекта брандмауэр не меняла | Портал и Jellyfin слушают `127.0.0.1`, поэтому от брандмауэра не зависят. Службы Windows (SMB 445, SSDP и др.) в домашней сети защищены им; `scripts\doctor.cmd` предупредит, если он снова выключится |
| **UAC выключен** (`EnableLUA=0`), пользователь `PC` — администратор | любой процесс этого пользователя, включая портал, работает с полными правами |
| Defender: защита в реальном времени и защита от подделки включены, сигнатуры свежие | — |
| Tailscale Serve: `443 → 8070` и `8443 → 8096`, только tailnet; Funnel выключен | — |
| **Tailscale: сервер объявлен выходным узлом** (`Self.ExitNodeOption=True`, `AllowedIPs` включает `0.0.0.0/0`) и в tailnet 5 устройств не видны 34–44 дня | любое устройство tailnet может направить трафик через ПК и дотянуться до домашней сети; потерянное устройство остаётся доверенным. Решение владельца: [owner-actions.md](owner-actions.md), пункты 1–2 |
| Адреса, на которых слушает ПК вне портала | SMB (445, 139), служба печати, оптимизация доставки Windows (7680) и `xray` (VPN-клиент): проект их не создаёт и не меняет; наружу защищены брандмауэром |

**Владельцу:** включить брандмауэр для частной сети («Безопасность Windows» → «Брандмауэр и защита сети» → «Частная сеть» → включить). Правила Tailscale и Jellyfin для частной сети уже есть, портал продолжит работать. Включить UAC — по желанию, после перезагрузки.
