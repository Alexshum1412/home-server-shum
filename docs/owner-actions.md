## Важно для безопасности

| # | Что | Почему | Как |
|---|---|---|---|
| 1 | **Выключить «выход через этот компьютер» (exit node) в Tailscale** | сейчас сервер объявлен выходным узлом: любое ваше устройство в tailnet может направить через него весь трафик и дотянуться до домашней сети (роутер, принтер). Если украдут телефон, это расширяет ущерб. Вы пользуетесь этим? Если нет — выключите | на ПК: `"C:\Program Files\Tailscale\tailscale.exe" set --advertise-exit-node=false`; затем в панели Tailscale (login.tailscale.com → Machines → server-home → «Edit route settings») убрать галочку Use as exit node |
| 2 | **Убрать из tailnet старые устройства** | в списке есть устройства, которых не видно 34–44 дня (3 старых iPhone, `desktop-shum1ch`): потерянное устройство остаётся доверенным, пока его не удалят | панель Tailscale → Machines → «…» → Remove |

## Убрать мусор, оставшийся после аудита (одноразово)

Один из проверяющих агентов по ошибке запустил пробу без изоляции, и она записала в настоящую папку семьи тестовые данные. Это не ваши файлы. Вечером 17.10.2026 в `C:\FamilyData\Files\users` появились папки `mama` (в ней только `Заметки\secret.txt`, 17 байт, текст «mama private text») и `mama.` (пустая, с точкой в конце: Проводник её не удалит). Агенту удалить их не разрешили, поэтому — вручную, в PowerShell:

```powershell
Remove-Item -LiteralPath '\\?\C:\FamilyData\Files\users\mama.' -Force
Remove-Item -LiteralPath 'C:\FamilyData\Files\users\mama' -Recurse -Force
Get-ChildItem 'C:\FamilyData\Files\users', 'C:\FamilyData\Photos\users' -Force | Select Name, CreationTime
```

Последняя команда показывает, что осталось: должна быть только ваша папка `alex` (и папки реальных людей, которых вы добавите). Если в `Photos\users` тоже есть `mama`, удалите её так же. Тесты больше так не делают: с этого дня они пишут только во временные папки (проверяется отдельным тестом).

## Для надёжности данных

| # | Что | Как |
|---|---|---|
| 6 | **Внешний USB-диск ≥ 2 ТБ вместо флешки на 14,9 ГБ** | по мере роста фото флешка переполнится. Назовите диск `reserve2`, добавьте в `.env`: `BACKUP_TARGETS=C:\FamilyServer\backups;label:reserve\FamilyServerBackups;label:reserve2\FamilyServerBackups`. Проверка: `scripts\backup.cmd` и `scripts\backup.cmd test-restore` |
| 7 | **Копия вне дома** | зашифрованная копия на облаке или у родственников: решаете вы (семейные данные в облако сами не отправляются). Подробно — [runbooks/backup-restore.md](runbooks/backup-restore.md) |
| 8 | **Диск `ST_M13FQBL`** | не форматировать и не использовать. Проверить SMART и кабели, лучше заменить: [runbooks/second-disk.md](runbooks/second-disk.md) |
| 9 | Закрепить IP компьютера и принтера в роутере | иначе после смены адреса не заработают запасной адрес и печать |

## Решения

- Выдать нужным людям права «Загрузки» и «Печать» («Администрирование» → «Управление»).
- Сменить временный пароль `alex` на свой («Мой профиль»), если ещё не сделали.
- Локальный ИИ для «Оливии»: рекомендуем не ставить (ADR-0008), но задел есть.
- Обновления Windows 10: поддержка закончена, нужна программа ESU или переход на новую версию (`docs/environment-audit.md`).
