# Видение (кратко)

Полный исходный документ: [`../01_vision_and_plan_family_server.md`](../01_vision_and_plan_family_server.md). Техническое задание для агента: [`../02_CLAUDE_CODE_SUPER_MASTER_PROMPT.md`](../02_CLAUDE_CODE_SUPER_MASTER_PROMPT.md).

**Цель.** Одна знакомая иконка «Семейный сервер» на телефоне и компьютере: фильмы, фото, файлы, загрузки, печать и состояние домашнего ПК — для родственников в разных странах, без IP-адресов, портов и командной строки.

**Принципы.**
1. Портал — входная точка, а не замена зрелым сервисам (Jellyfin, Immich, файловый сервис подключаются отдельно).
2. Честность: показывать только проверенные состояния; «не настроено», «нет данных» и «ошибка проверки» — это нормальные, понятные состояния.
3. Приватность: доступ только дома (локально) и через Tailscale; ничего не публикуется в интернет.
4. Компьютер остаётся обычным домашним ПК с Windows и HDMI.
5. Поэтапность: сначала надёжный портал и доступ, потом медиатека, файлы и бэкап, потом всё остальное; «Оливия» — последней.

**Что значит «автономно».** Дома без интернета работает то, что не требует WAN. Из-за границы доступ есть, только когда домашний ПК включён, пользователь вошёл в Windows (или Tailscale в режиме unattended) и дома есть интернет. PWA кэширует только оболочку интерфейса — данные без сервера недоступны.
