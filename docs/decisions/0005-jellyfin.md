# ADR-0005: Медиасервер Jellyfin — переносимая сборка под супервизором, доступ только через tailnet

**Статус:** принято, реализовано 17.10.2026.

## Контекст

Нужен настоящий домашний кинотеатр (этап P2 ТЗ):
- фильмы и сериалы для семьи дома и за границей;
- без Docker и WSL2 — их нет, а включение компонентов Windows ТЗ запрещает;
- без открытия административного интерфейса в интернет;
- с автозапуском и восстановлением после сбоя.

Ресурсы ПК: i5-6400 (4 ядра), 16 ГБ ОЗУ, GTX 960 (2 ГБ), один исправный HDD на 2 ТБ.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Установщик Jellyfin как служба Windows | официальный путь | служба по умолчанию от LocalSystem; документация Jellyfin не советует режим службы; установщик меняет систему (программы, правила) |
| Установщик в режиме «трей» | официальный путь | работает только после входа пользователя; без перезапуска после сбоя |
| Docker / WSL2 | привычно на Linux | на ПК нет; нужны компоненты Windows, перезагрузка и память |
| **Официальный ZIP (portable) + наш супервизор** | без изменений системы; от имени владельца с обычными правами; запуск до входа в Windows (задача «FamilyServer», S4U); перезапуск после сбоя и зависания; мягкая остановка через API | обновление — вручную (заменить папку); бинарники Jellyfin не подписаны Authenticode — целостность проверяется по SHA-256 с repo.jellyfin.org |

## Решение

1. **Установка.**
   - Jellyfin **12.2** (последняя стабильная на 17.10.2026): ZIP `jellyfin_12.2-amd64.zip`.
   - SHA-256 `ab247745…d83f` совпал с опубликованным на repo.jellyfin.org.
   - Программа лежит в `C:\FamilyServer\apps\jellyfin`.
   - Данные, конфигурация, кэш и логи — в `C:\FamilyServer\data\jellyfin\{data,config,cache,log}`. Права у этой папки — только PC, SYSTEM и администраторы.
2. **Медиатека.**
   - Папки `C:\FamilyData\Media\{Фильмы,Сериалы,Мультфильмы,Домашнее видео,Музыка}`, права — только PC, SYSTEM и администраторы.
   - Неисправный второй диск не используется.
3. **Сеть.** Настройки в `config\network.xml`:
   - Jellyfin слушает **только `127.0.0.1:8096`**;
   - автообнаружение (UDP 7359) и UPnP выключены;
   - удалённый доступ вне «локальных» сетей выключен;
   - «локальные» сети — loopback и `100.64.0.0/10` (tailnet);
   - доверенный прокси — `127.0.0.1`.

   Семья открывает **`https://server-home.tail89d77e.ts.net:8443`**: Tailscale Serve, только tailnet, Funnel выключен.
   - Отдельный порт, а не путь `/jellyfin`: так не нужен BaseUrl, а BaseUrl ломает часть клиентов (из документации Jellyfin).
   - Брандмауэр Windows не менялся.
4. **Запуск.**
   - Супервизор (ADR в OpenSpec `add-first-admin-and-autostart`) запускает Jellyfin, если найден `jellyfin.exe`.
   - Мягкая остановка — `POST /System/Shutdown` с ключом API «FamilyServer». Ключ лежит в `C:\FamilyServer\data\dashboard\jellyfin-api.json`, не в Git.
5. **Первичная настройка** — `scripts\jellyfin-setup.cmd`, повторный запуск безопасен:
   - мастер: русский язык, администратор `alex` со случайным паролем, показанным один раз;
   - библиотеки **без** trickplay-превью и картинок глав: они пережимают каждый фильм целиком и на i5-6400 заняли бы часы.
6. **Перекодирование.**
   - NVENC GTX 960 (`HardwareAccelerationType=nvenc`).
   - Аппаратное декодирование: H.264, HEVC (вкл. 10 бит), MPEG-2, VC-1, VP9.
   - Тонмаппинг HDR (CUDA), дросселирование, удаление сегментов.
7. **Портал.**
   - Карточка «Кинотеатр»: `openUrl` = адрес Jellyfin в tailnet, `healthUrl` = `http://127.0.0.1:8096/health`.
   - Поле `process: "jellyfin"` в `services.json` — портал показывает «Остановлен» или «Сбой: перезапускается» по данным супервизора, а не просто «не отвечает».

## Измерения (17.10.2026, этот ПК)

| Что | Результат |
|---|---|
| Запуск Jellyfin | «Startup complete» за 14,8 с (первый запуск — с созданием базы) |
| Простой | ~200–220 МБ ОЗУ |
| Прямое воспроизведение 1080p H.264 6 Мбит/с в Chrome (Jellyfin Web) | DirectPlay, 30,3 с видео за 30,7 с, 0 потерянных кадров; Jellyfin **0,39 % CPU** машины, 204 МБ |
| Поток `static=true` через HTTPS tailnet | 92 613 550 байт; SHA-256 совпал с исходным файлом; Range-запросы — 206 |
| Принудительное перекодирование Jellyfin → 720p 1,2 Мбит/с (HLS, через tailnet) | `-hwaccel cuda`, `scale_cuda`, `h264_nvenc`; скорость 6,8–7,6× реального времени |
| ffmpeg: синтетическое 4K HEVC 10 бит → 1080p H.264 | CPU (libx264 veryfast): 2,3× реального времени, ~3 ядра заняты; NVENC: 2,4× почти без CPU |

**Ограничения измерений.**
- Источники синтетические: тестовая таблица `testsrc2`, кодируется легче настоящего фильма.
- Настоящий 4K HDR (HEVC 10 бит, высокий битрейт) с тонмаппингом **не проверялся** — подходящего файла нет. Поэтому перекодирование тяжёлого 4K HDR **не обещается**.
- Ожидание: одно перекодирование 4K → 1080p на NVENC, вероятно, возможно; несколько одновременно — нет.
- Лучше всего, когда устройство воспроизводит файл само (DirectPlay).

## Риски и меры

- **Потоки без входа.** Jellyfin отдаёт `/Videos/{id}/stream` без входа, если известен ID элемента. Это известная особенность Jellyfin: ID — хэш пути.
  - Мера: порт 8096 доступен только с этого ПК, 8443 — только устройствам tailnet. Посторонние в tailnet не допускаются.
  - Дополнительно можно ограничить доступ ACL Tailscale по пользователям — это решение владельца, проект ACL не меняет.
- **Администратор Jellyfin.** Пароль администратора Jellyfin независим от пароля портала. Владельцу нужно сменить его, а для родственников создать отдельных пользователей Jellyfin без прав администратора (`docs/runbooks/jellyfin.md`).
- **Обновления.** Jellyfin не обновляется сам. Порядок обновления — в ранбуке: скачать ZIP, сверить SHA-256, остановить через супервизор, заменить папку, запустить.
- **Резервные копии.** Конфигурация и база Jellyfin входят в ежедневную копию с этапа P5. Сами фильмы в копию не входят: их объём больше флешки (см. ADR-0004 и `backup-restore.md`).
