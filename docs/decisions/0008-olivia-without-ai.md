# ADR-0008: «Оливия» — правила без нейросети; локальная LLM пока не ставится

**Статус:** принято, реализовано 17.10.2026.

## Контекст

Этап P6 ТЗ:
- сначала надёжная система правил и диагностики без ИИ;
- локальную LLM оценивать только после стабильной работы сервера;
- никаких shell-команд, `eval` и автоматического удаления данных;
- действия только из списка, с проверкой, журналом и подтверждением администратора;
- без ИИ всё основное должно работать.

## Решение

1. **Мониторинг** — без ИИ, раньше и независимо от «Оливии». `GET /api/system` отдаёт:
   - CPU, память, место на дисках, физические диски, Tailscale, принтер, резервную копию;
   - **программы супервизора** (портал, Jellyfin: работает / сбой / остановлен, число перезапусков);
   - **общий итог** в четырёх уровнях: «работает / предупреждение / ошибка / неизвестно».

   Опрос лёгкий:

   | Что | Как часто |
   |---|---|
   | CPU | раз в 5 с |
   | программы | раз в 10 с |
   | место и копии | раз в минуту |
   | Tailscale | раз в минуту |
   | диски и принтер | раз в 5 минут |
   | сервисы | раз в минуту |

2. **«Оливия»** (`server/src/olivia`) — правила над уже измеренными значениями:
   - сбой, остановка или зависание Jellyfin;
   - проблемы копии: не удалась, устарела, не настроена, восстановление не проверялось;
   - мало места, состояние дисков, Tailscale, память;
   - недоступные сервисы;
   - неудачные входы и блокировки за сутки;
   - не запущен супервизор.

   Каждая находка состоит из уровня, объяснения простыми словами и совета. Ничего не угадывается.
3. **Действия** — только четыре, список зашит в коде (`OLIVIA_ACTIONS`): перезапустить Jellyfin, запустить Jellyfin, сделать копию сейчас, перепроверить сервисы. У каждого:
   - проверка применимости к текущему состоянию — иначе 409 и запись в журнал;
   - обязательное `{confirm: true}`: в интерфейсе это диалог подтверждения;
   - не чаще раза в 30 с;
   - запись `olivia.action` в журнал аудита.

   Команды не берутся ни из запроса, ни из текста находок. Свободное место «Оливия» не освобождает — она только советует.
4. **Выключение одной настройкой:** `OLIVIA_ENABLED=0` → API отвечает 404, блок исчезает из интерфейса, мониторинг продолжает работать (проверено тестом).

## Оценка локальной LLM (17.10.2026)

| Ресурс | Факт | Вывод |
|---|---|---|
| CPU | i5-6400, 4 ядра без HT, AVX2 | генерация на CPU: по публичным замерам llama.cpp — порядка единиц токенов в секунду для моделей 3B в 4-битном квантовании; ответ в 150 слов — десятки секунд, при этом CPU занят полностью |
| GPU | GTX 960, 2 ГБ (по WMI), Maxwell | в 2 ГБ помещаются только модели примерно до 1,5B в 4 битах; они заметно хуже по-русски и в технических объяснениях |
| ОЗУ | 16 ГБ: Windows + портал + Jellyfin | модель 3–7B заняла бы 3–6 ГБ и конкурировала бы с перекодированием в Jellyfin |
| Польза | правила уже объясняют все измеряемые ситуации простыми словами | LLM добавила бы только перефразирование, но и риск выдуманных советов |

**Вывод:** большая модель «ради наличия ИИ» не ставится — ТЗ прямо это запрещает. Цифры выше — оценка по публичным данным, на этом ПК не измерялись: ничего не устанавливалось.

**Если владелец позже захочет ИИ** (например, после замены ПК), безопасные рамки:
- Ollama с небольшой моделью, только на `127.0.0.1`;
- ИИ получает обезличенные находки «Оливии», а не логи с адресами и именами файлов;
- ИИ только переформулирует и объясняет — действия по-прежнему выбираются из того же списка в коде и выполняются после подтверждения;
- отдельная настройка `OLIVIA_LLM=0/1`, выключено по умолчанию.
