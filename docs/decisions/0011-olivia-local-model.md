# ADR-0011: «Оливия» для всей семьи — только локальная модель, инструменты только из списка

**Статус:** принято 18.10.2026. Уточняет [ADR-0008](0008-olivia-without-ai.md) (там — помощница администратора без модели; она остаётся).

## Контекст

Решение владельца: «Оливия» — единственный ИИ портала. Никаких облачных моделей, никакого скрытого обращения к чужим ИИ-сервисам. Она должна помогать всей семье (найти фильм, фото, файл, объяснить, как пользоваться порталом, показать загрузки), а не только администратору. ПК: i5-6400 (4 ядра, без HT), 16 ГБ ОЗУ, GTX 960 с **2 ГБ** видеопамяти (при работе Jellyfin около 1,1 ГБ занято), Windows 10.

## Решение

1. **Две ступени, модель необязательна.**
   - Сначала вопрос разбирают правила (`server/src/olivia/assistant/router.ts`): понятные формулировки решаются сразу и мгновенно.
   - Если правила не уверены и модель подключена, модель **только выбирает инструмент и слоты** из закрытого списка (поиск фильма, поиск файла, место на диске, загрузки, календарь, проверка ссылки, справка). Ответ модели — одна строка JSON; всё, что не из списка, отбрасывается.
   - Нет модели, она не отвечает или ошиблась — работают правила; интерфейс честно пишет «Языковая модель не подключена» (или «не отвечает»). Ничего не выдумывается.
2. **Модель не видит данные семьи.** Ей отправляется только текст вопроса и описание инструментов. Результаты (названия фильмов, имена файлов, события календаря) в модель не уходят: ответ собирает код по шаблонам из фактов. Адрес или поисковый запрос, который «выбрала» модель, должен буквально присутствовать в сообщении человека — иначе отбрасывается.
3. **Права человека.** Каждый инструмент работает с правами того, кто спросил: чужие личные файлы, чужие чаты и события не видны (в том числе администратору). Загрузки — только при праве `downloads`.
4. **Оливия ничего не меняет сама.** Нет инструментов «скачать», «удалить», «перезапустить» для семьи. Для ссылки она запускает только проверку (то же окно с кнопкой «Скачать», что и в «Загрузках»): старт — нажатием человека. Четыре административных действия из ADR-0008 остаются отдельными, с подтверждением, только у администратора. Через внешний адрес (см. [ADR-0013](0013-remote-access-public-https.md)) проверку ссылок она не готовит.
5. **Журнал.** В аудит пишется только вид помощи («поиск фильма»), не текст вопроса.
6. **Только этот ПК.** `OLIVIA_LLM_URL` принимает лишь адрес на `127.0.0.1`/`localhost`/`[::1]` (проверяется при чтении настроек). Сервер модели слушает только `127.0.0.1`.

## Выбор среды и модели

| Решение | Выбрано | Почему |
|---|---|---|
| Среда | `llama-server` из llama.cpp, сборка для процессора (Windows x64), порт 8081, OpenAI-совместимый `/v1` | один исполняемый файл с DLL, без Python/Docker/WSL; интерфейс совпадает с тем, что уже умеет клиент портала |
| Железо | **процессор**, не видеокарта | в 2 ГБ видеопамяти при занятых Jellyfin 1,1 ГБ модель не поместится без борьбы за видеопамять с перекодированием фильмов |
| Модель | Qwen2.5-1.5B-Instruct, квантование Q4_K_M, файл около 1,1 ГБ | хорошо держит русский и строгий JSON для своего размера; в памяти около 1,3–1,6 ГБ вместе с контекстом 2048; лицензия Apache-2.0 |
| Запасная модель | Qwen2.5-1.5B Q5_K_M (около 1,3 ГБ) или Qwen2.5-3B Q4_K_M (около 2 ГБ) | если 1,5B ошибается слишком часто; 3B медленнее примерно вдвое |
| Контекст и потоки | `-c 2048`, `-t 3`, один запрос за раз | оставляет ядро Jellyfin и порталу; вопросы короткие |

**Память и скорость — оценка, не измерение.** Модель на этом ПК ещё не установлена (нужно согласие владельца на загрузку ~1,1 ГБ, см. [runbooks/local-ai.md](../runbooks/local-ai.md)). Ожидание для 1,5B Q4 на 4 ядрах Skylake: порядка 5–10 токенов в секунду; выбор инструмента — это 20–40 токенов, то есть несколько секунд. После установки замеры нужно записать в runbook (скрипт и порядок там описаны). Пока замеров нет, заявлять скорость нельзя.

## Управление моделью

- Запуск и остановка — супервизором, как Jellyfin: программа `llama` появляется, только если установлены `llama-server.exe` и файл модели и в `.env` задан `OLIVIA_LLM_URL`. Ручное управление: `scripts\service.cmd status|start|stop|restart llama`.
- Обновление: заменить сборку командой установщика (`scripts\ai-setup.cmd`), прежняя папка переименовывается, не удаляется.
- Смена модели: положить другой GGUF в `C:\FamilyServer\data\models`, указать путь в `OLIVIA_MODEL_FILE`, перезапустить `llama`. Имя в `OLIVIA_LLM_MODEL` — только подпись.
- Отключение: убрать `OLIVIA_LLM_URL` из `.env` — «Оливия» продолжит работать на правилах.

## Последствия

- Без модели семья получает рабочую помощницу на правилах; с моделью — понимание более свободных вопросов.
- Ошибки модели безопасны по построению: худшее, что она может, — выбрать не тот инструмент из списка или промолчать.
- Сторонний ИИ, облако и телеметрия не используются нигде в проекте.
