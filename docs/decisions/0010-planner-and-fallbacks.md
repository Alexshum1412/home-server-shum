# ADR-0010: календарь и заметки внутри портала; два способа для каждой функции

**Статус:** принято, реализовано 17.10.2026.

## Контекст

- P10 ТЗ: семейный календарь и общие заметки, аудиокниги. Новые компоненты допустимы, только если они не съедают память, совместимы с Windows 10 без Docker/WSL/Python и имеют понятное резервирование.
- Требование владельца к архитектуре: у каждой важной функции — основной и рабочий запасной путь, без «заглушек».
- Семье нужно как можно меньше приложений.

## Решения

### Календарь и заметки — встроены в портал

| Вариант | Итог |
|---|---|
| Radicale / Baikal (CalDAV) | отклонено: нужен Python или PHP, на ПК их нет, ставить ради календаря не нужно |
| Nextcloud Calendar | отклонено: Nextcloud не работает на Windows (ADR-0007) |
| **Свой модуль в портале** | принято: без новых программ и памяти, те же вход, роли и копии |

- **Календарь.** Файл `calendar.json` в папке данных портала (уже входит в каждую копию). События общие или личные; личные не видит никто, даже администратор. Даты — строки `ГГГГ-ММ-ДД` без часовых поясов: день рождения не «съезжает» из-за перевода часов. Повторы (неделя, месяц, год) считаются при чтении; несуществующие даты (31-е, 29 февраля) пропускаются так же, как в iCalendar. Автор и администратор меняют и удаляют. Повреждённый файл не перезаписывается (ошибка 503).
- **Запасной путь календаря:** файл `.ics` (RFC 5545) — открывается в календаре телефона и ПК, печатается; «плавающее» время без часового пояса. Подписки (CalDAV) нет: для неё нужен вход с телефона по токену в адресе, а это новая поверхность атаки без большой пользы.
- **Заметки** — обычные `.txt` в папке «Заметки» раздела «Файлы». Запасной путь — сама файловая система: Файлы, Проводник, импорт/экспорт, копии. Сохранение поверх чужой правки отклоняется (версия = время и размер файла).
- Напоминания на телефон (web push) не делаются: для iOS нужен установленный PWA и ключи VAPID — много сложности ради малой пользы. Вместо этого события «сегодня и завтра» показаны на главной.

### Аудиокниги — Jellyfin, без нового сервиса

Библиотека «Аудиокниги» типа «Книги» (папка `C:\FamilyData\Media\Аудиокниги`). Проверено: Jellyfin 12.2 распознаёт файлы как `AudioBook`. Запасной путь — встроенный плеер (см. ниже). Отдельное приложение для аудиокниг не нужно.

### Запасные способы — по одному на функцию, только реальные

См. [feature-fallback-matrix.md](../feature-fallback-matrix.md). Принципы:

1. **Тот же результат другим путём.** Не вторая копия системы, а другой доступ, резервная процедура или встроенный режим.
2. **Опасное выключено, пока владелец не включит.** Запасной адрес в домашней сети (`LAN_BIND`) требует правила брандмауэра — его создаёт и убирает владелец командой `scripts\lan-mode.cmd`; проект брандмауэр сам не меняет. Портал слушает свой адрес **дополнительно** к `127.0.0.1`, не `0.0.0.0`; принимаются только частные адреса (192.168/16, 10/8, 172.16/12).
3. **Запасной путь не расширяет права.** Запасной просмотр кино читает только `C:\FamilyData\Media`, только в режиме чтения, только вошедшим; переносы файлов (`import`/`export`) идут через тот же код хранилища с теми же запретами; очередь печати не печатает без явного выбора пользователя и держит документ не дольше суток.
4. **Честность.** Что не проверено физически (телефон, выключенный принтер), помечено как проверка владельца; ИИ для «Оливии» остаётся «не подключён».

### Локальный ИИ для «Оливии»

Задел сделан так, как требовал ADR-0008: `OLIVIA_LLM_URL` пустой по умолчанию, допускается только адрес на этом же ПК, модель получает одну находку без адресов и папок, отвечает текстом, который очищается и подписывается как машинный, и никогда не выбирает и не запускает действие. Модель на ПК **не установлена**.

## Последствия

- Нет новых зависимостей и фоновых программ.
- `calendar.json` и заметки попадают в копии без изменений кода резервного копирования (верхнеуровневые `*.json` данных и дерево «Файлы»).
- Меньше шансов, что семья «застрянет»: для каждой функции есть путь, который не зависит от того, что именно сломалось.
