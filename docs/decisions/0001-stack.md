# ADR-0001. Стек семейного дашборда

- **Статус:** принято · 15.10.2026
- **Контекст:** чистая Windows 10 Home 22H2 (установлена 15.10.2026), i5-6400, 16 ГБ RAM, нет Docker/WSL2, нет winget, Git, Node.js и Python. Нужен небольшой, надёжный портал: страница со ссылками на отдельные сервисы, честные статусы, вход family/admin, PWA. Инструменты разработки, которые требует ТЗ (OpenSpec, Playwright CLI, skills CLI), работают на Node.js, поэтому Node.js на машине нужен в любом случае.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. Node.js 24 LTS + TypeScript: Fastify (backend) + Preact/Vite (frontend), один `package.json`** | один runtime на всё (приложение, тесты, OpenSpec, Playwright); общие типы API между сервером и клиентом (`shared/api.ts`); Node 24 запускает `.ts` напрямую (type stripping) — без отдельной сборки сервера; Fastify — зрелый, со встроенной валидацией схем, лимитом тела, логированием с редактированием секретов; Preact ≈ 4 КБ и экранирует вывод (защита от XSS по умолчанию) | метрики системы на Windows приходится собирать самим (CPU из `os.cpus()`, диски через `fs.statfs` и read-only вызовы PowerShell) |
| B. Python 3 + FastAPI + отдельный frontend на Vite | FastAPI назван в видении предпочтительным; `psutil` даёт метрики «из коробки»; Python удобен для будущей «Оливии» | **второй** runtime (Python + Node всё равно нужен для сборки фронтенда, OpenSpec и Playwright); два менеджера пакетов, venv на Windows, дублирование типов API |
| C. Только статический HTML без backend | минимум кода | нельзя честно проверять сервисы (CORS, внутренние адреса), нельзя сделать вход и роли, нельзя читать метрики |

## Решение

Вариант **A**.

- **Runtime:** Node.js 24 LTS, установлен **для текущего пользователя без прав администратора** (официальный ZIP с проверкой SHA-256).
- **Backend:** Fastify 5 (+ `@fastify/static`, `@fastify/cookie`), TypeScript запускается напрямую через type stripping Node 24, `tsc --noEmit` — только проверка типов.
- **Frontend:** Preact + Vite, без UI-фреймворков; иконки — `lucide-preact` (собираются в бандл, без CDN); шрифты — системные.
- **Хранение:** без СУБД. Пользователи, сессии, конфигурация сервисов и журнал аудита — небольшие JSON/JSONL-файлы в каталоге данных **вне репозитория** (`%LOCALAPPDATA%\FamilyDashboard` по умолчанию). Атомарная запись (temp + rename).
- **Пароли:** `crypto.scrypt` из стандартной библиотеки Node (без нативных модулей).
- **Тесты:** Vitest (unit + интеграционные через `fastify.inject`), Playwright Test в установленном Google Chrome (`channel: 'chrome'`, без скачивания браузеров) + `@axe-core/playwright` для доступности.
- **Lint/format:** Biome (один инструмент вместо ESLint + Prettier).

## Последствия

- Одна команда установки (`npm ci`) и один набор команд проверки (`npm run check`).
- FastAPI не используется в MVP. Если «Оливии» (P5) понадобится Python-экосистема, её можно сделать отдельным локальным сервисом, которому дашборд передаёт уже собранные метрики через строго типизированный API — не переписывая портал.
- Метрики, для которых у Windows/Node нет поддерживаемого источника (температура, тонер), возвращаются как `null` с причиной.
