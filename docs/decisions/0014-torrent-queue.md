# ADR-0014: торренты — очередь в портале поверх aria2 на loopback

**Статус:** принято 18.10.2026. Код и автотесты готовы; клиент aria2 **не установлен** на этом ПК (нужно согласие владельца на загрузку 2,4 МБ), реальная раздача не скачивалась — статус «Требует внешней настройки».

## Контекст

Нужна полная очередь торрентов в портале и в «Оливии» через API готового клиента: состояние, прогресс, скорость, оставшееся время, ошибки, завершённые; пауза, продолжение, отмена, повтор; обновление Jellyfin после завершения; проверка адреса, ограниченные папки, защита от SSRF, лимиты; API не публичный. Только законные раздачи.

## Решение

- **Клиент:** aria2 1.37.0 (один `aria2c.exe`, GPL). Слушает **только** `127.0.0.1:6800`, секрет RPC лежит в `aria2-rpc.json` в папке данных портала и в файле `aria2.conf` (не в командной строке — её читает любая программа). Права файла на Windows задаёт папка; программа с правами этого пользователя секрет прочитает — это принятый риск (клиент слушает только loopback). Запуск и остановка — супервизором (`aria2`), корректное завершение через RPC.
- **Портал разбирает раздачу сам**, прежде чем отдать клиенту: `.torrent` читается и пересобирается (удаляются `url-list`, `httpseeds` и небезопасные трекеры), магнет очищается от `ws`, `xs`, `as`. Показывается, что внутри и сколько места нужно. **Программы и скрипты (.exe, .bat, .ps1 …) пропускаются** (`select-file`), остальное качается.
- **Куда:** фиксированный список — «Файлы → Личное → Загрузки» или папки общей медиатеки (Фильмы, Сериалы, Мультфильмы, Музыка). Произвольный путь задать нельзя.
- **Защита:** адреса трекеров проверяются на внутренние/локальные адреса (SSRF, в том числе после разрешения имени); лимит размера и проверка свободного места; число одновременных загрузок 3; раздача ограничена `TORRENT_SEED_RATIO` (1) и `TORRENT_UPLOAD_LIMIT_KB` (500 КБ/с), чтобы не забить домашний канал. DHT и обмен пирами включены, локальное обнаружение и IPv6 выключены.
- **Права:** право `downloads`; обычный человек видит и управляет только своими загрузками, администратор — всеми.
- **После завершения:** запись в журнал, уведомление владельцу, для папок медиатеки — обновление библиотеки Jellyfin; метка `Zone.Identifier` на файлах.
- **«Оливия»:** показывает очередь и готовит проверку ссылки; запускает загрузку только человек кнопкой.
- **Недоступность:** если клиент не установлен или не отвечает, раздел «Загрузки» показывает «Торренты сейчас недоступны» и причину; прямые ссылки продолжают работать независимо.
- **Публичный канал:** запуск/управление закрыты (ADR-0013).

## Законность

Портал не ищет раздачи и не содержит каталогов. Ответственность за содержимое — на человеке, который добавляет ссылку; интерфейс напоминает, что можно скачивать только то, что вам разрешено.

## Альтернативы

qBittorrent (Web UI + тяжелее, больше поверхность), Transmission (нет нормальной Windows-сборки с RPC в один файл), встроенный торрент-клиент на Node (много кода и рисков) — отклонены.
