# Безопасность

Коротко: портал слушает только `127.0.0.1`, наружу его выводит только Tailscale Serve внутри частной сети (tailnet). Вход по паролю, роли `family`/`admin` проверяются на сервере. Секретов в репозитории нет.

## Модель угроз (что защищаем и от кого)

| Риск | Мера | Статус |
|---|---|---|
| Доступ из интернета | нет проброса портов, нет Funnel, сервер слушает `127.0.0.1`; удалённо — только устройства tailnet через Serve | Implemented |
| Гости в домашнем Wi-Fi | LAN-доступ выключен по умолчанию; при включении — правило Firewall только для профиля Private и `LocalSubnet` + обязательный вход | Not configured (по решению пользователя) |
| Чужой/потерянный телефон в tailnet | вход по паролю обязателен, Tailscale ≠ авторизация; сессии можно отозвать сменой пароля | Implemented |
| Подбор пароля | ≥10 символов; 10 неудач на имя / 30 на адрес за 15 мин → 429; scrypt (N=2^15); подбор текущего пароля в форме смены пароля считается так же | Implemented |
| Стандартный / общий пароль | в исходниках паролей нет; первый пароль — случайный временный (`--generate-password`, ~116 бит), показывается один раз, действует 7 дней и только до смены на свой (до этого все API, кроме смены пароля, → 403) | Implemented |
| Кинотеатр Jellyfin | слушает только `127.0.0.1:8096`, автообнаружение и UPnP выключены; семья — через Tailscale Serve `:8443` (только tailnet); отдельные пароли Jellyfin. **Особенность Jellyfin:** поток файла (`/Videos/{id}/stream`) отдаётся без входа, если известен ID элемента — поэтому порт доступен только с этого ПК и из tailnet | Implemented (риск принят: только устройства семьи в tailnet) |
| Процессы сервера | портал и Jellyfin запускает супервизор от имени владельца с обычными правами (задача «FamilyServer», S4U — пароль Windows не хранится); команды и пути программ заданы в коде, управление — только через именованный канал на этом ПК | Implemented |
| CSRF / чужие сайты | cookie `SameSite=Strict`, `HttpOnly`; POST только с `application/json` и своим `Origin`; `Sec-Fetch-Site: cross-site` → 403; проверка идёт по найденному маршруту, поэтому закодированный путь (`/%61pi/...`) её не обходит | Implemented |
| DNS-rebinding со страницы, открытой на самом сервере | сервер отвечает только на известные имена (`Host`/`X-Forwarded-Host`): `127.0.0.1:8070`, `localhost:8070`, `[::1]:8070`, имя из `PUBLIC_URL`, имя из `LAN_URL` (и `127.0.0.1:5173`/`localhost:5173` для dev-сервера Vite — только с loopback); остальное → 421. Без этого чужая страница могла бы подбирать пароли и подделывать `X-Forwarded-For`, обходя лимит по адресу | Implemented |
| XSS | Preact экранирует вывод; нет `innerHTML`; CSP `script-src 'self'` без inline-скриптов | Implemented |
| Утечка через логи | pino `redact` для `cookie`, `authorization`, `password`; журнал аудита без паролей/токенов | Implemented |
| Выполнение команд | в UI/API нет shell, перезапусков, просмотра файлов; системные пробы — фиксированный allowlist read-only команд PowerShell без пользовательских аргументов | Implemented |
| Неподдерживаемая Windows 10 | только loopback + tailnet; рекомендация — ESU/обновления (см. `environment-audit.md`) | Требует действия пользователя |
| Отказ единственного диска | ежедневная проверяемая копия на флешку «reserve» (+ копия на `C:` от удаления/порчи); результат на дашборде | Implemented |
| Кража, пожар, потеря флешки | копии вне дома нет; копии не зашифрованы — при потере флешки сменить пароли | Partial (нужна зашифрованная копия вне дома — решение владельца) |
| Утечка семейных данных через GitHub | в GitHub — только код; данные, `.env`, логи и копии вне репозитория и в `.gitignore` | Implemented (публикация кода — после подтверждения владельца) |

## Роли

- **family** — главная, сервисы, состояние системы без технических деталей (без имён устройств, моделей дисков, имени хоста).
- **admin** — всё то же + технические детали, журнал аудита, список пользователей (только чтение), диагностический отчёт, ручная проверка сервисов.
- Учётные записи создаются только на сервере: `scripts\user.cmd add <логин> --name "<Имя>" --role family|admin`. Регистрации из браузера нет.

## Сессии

- Cookie `fd_session`: случайный токен 256 бит, `HttpOnly`, `SameSite=Strict`, `Secure` при HTTPS (Tailscale Serve).
- На диске хранится только SHA-256 токена; срок — 30 дней неактивности; при смене пароля все сессии пользователя становятся недействительными.

## Секреты

- В репозитории секретов нет и не требуется: подпись cookie не используется, `.env` необязателен.
- `.env`, ключи, сертификаты, базы и каталоги данных перечислены в `.gitignore`.
- Пароли пользователей вводятся без отображения и хранятся только как хэши scrypt.

## Данные, права и резервные копии

- Всё серверное — в `C:\FamilyServer`. Права NTFS: на корне и `tools\` — полный доступ у PC, SYSTEM и администраторов, у «Пользователей» — только чтение и выполнение; на `data\` (данные портала) и `backups\` — только PC, SYSTEM и администраторы.
- Копия содержит `users.json` (хэши паролей scrypt), журнал аудита, `.env` (сейчас в нём нет секретов — только пути) и код. Сессии (`sessions.json`) в копию не входят.
- Копии **не зашифрованы**. На флешке права NTFS не защищают: её можно прочитать на любом компьютере (на `D:\FamilyServerBackups` сейчас полный доступ у «Все»). Защита — физическое хранение флешки; если она потеряна — сменить пароли всех пользователей.
- Восстановление пишет только в новую пустую папку, никогда в рабочую папку данных; папку восстановления после использования удалить. Рекомендуемое место — внутри `C:\FamilyServer\data\` (наследует ограниченные права).
- Вывод CLI копирования и `backup-status.json` содержат имена файлов и причины ошибок, но не содержимое файлов.
- Репозиторий `https://github.com/Alexshum1412/home-server-shum` — **публичный** и содержит только код и документацию (опубликован с согласия владельца 17.10.2026). В нём нет `.env`, данных, логов и копий (`.gitignore`; проверено через GitHub API). Автор коммитов — служебный адрес `198652125+Alexshum1412@users.noreply.github.com`, личный e-mail не публикуется. Публичны описание ПК и сети (имя узла в tailnet, домашний IP, сведения об обновлениях Windows) — доступа это не даёт, портал доступен только в tailnet.
- Вход в GitHub выполнил владелец (Git Credential Manager, браузер); токен хранится в «Диспетчере учётных данных» Windows этого пользователя и даёт право отправки в его репозитории. Отозвать: GitHub → Settings → Applications → Git Credential Manager. Ежедневная задача отправляет код только fast-forward, без `--force` и без окон входа.

## Сеть и порты

| Порт | Адрес | Кто | Зачем |
|---|---|---|---|
| 8070/TCP | `127.0.0.1` | node.exe (дашборд) | портал и API |
| 443/TCP | Tailscale-интерфейс | tailscaled (Serve) | HTTPS в tailnet → `127.0.0.1:8070` |
| 8096/TCP | `127.0.0.1` | jellyfin.exe | кинотеатр (Jellyfin) |
| 8443/TCP | Tailscale-интерфейс | tailscaled (Serve) | HTTPS в tailnet → `127.0.0.1:8096` (Jellyfin) |
| 8071, 8072 | `127.0.0.1` | только во время e2e-тестов | изолированные тестовые серверы |

Проект **не меняет** Windows Firewall, Defender, UAC, SmartScreen, политики выполнения, ACL/DNS/маршруты Tailscale.

## Заголовки HTTP

`Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; manifest-src 'self'; worker-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Cross-Origin-Opener-Policy: same-origin`, `Permissions-Policy` без камеры/микрофона/геолокации, `X-Robots-Tag: noindex`. API — `Cache-Control: no-store`. Лимит тела запроса — 64 КиБ.

## Запрещено (для людей и агентов)

Funnel и проброс портов; отключение Defender/Firewall/UAC/обновлений; изменение ACL Tailscale; форматирование/разметка дисков (особенно устройства `ST_M13FQBL`); `eval`/`exec` данных пользователя или ИИ; выполнение команд из ответов LLM; загрузка семейных данных во внешние облака без явного решения пользователя.

## Будущая «Оливия» (P5)

Только интерпретация уже собранных метрик; действия — через фиксированный allowlist в коде с валидацией параметров, таймаутами, журналом и подтверждением человека; полное отключение одной настройкой.
