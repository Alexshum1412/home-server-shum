# Что дальше (после этапа 19–20.10.2026)

_Обновлено: 20.10.2026._ Общий план и история — [roadmap.md](roadmap.md); состояние сейчас — [EXECUTION_STATUS.md](EXECUTION_STATUS.md); что нужно от владельца — [owner-actions.md](owner-actions.md). Здесь — упорядоченные следующие шаги и **исследовательский список локальных интеграций**. Ничего из этого списка не установлено и не проверялось установкой: это разбор по документации проектов и по ограничениям сервера. Любая установка — только с вашего явного «да», с проверкой источника и SHA-256.

## 0. Что мешает всему остальному

Сначала — оборудование: за неделю в журнале Windows одиннадцать неожиданных выключений и аппаратные ошибки, связанные с неисправным диском `ST_M13FQBL` ([owner-actions.md](owner-actions.md), раздел «Оборудование»). Пока ПК перезагружается сам, любая новая функция может быть прервана на середине, а резервные копии — единственная защита. До выяснения причины новых компонентов не ставим.

## 1а. «Идеи» владельца от 20.10.2026: что сделано, что нет и почему

Сделано в самом портале (без новых программ): утренний дайджест с личным текстом от локальной модели (погода, курсы, дела, события, сроки, статус сервера; Telegram — после ключа бота); сроки и гарантии с напоминаниями; прогноз заполнения диска; журнал происшествий; статус для семьи; проверка «интернет есть, но DNS не отвечает»; приманки; устройства домашней сети с уведомлением о новых; переключатели всех функций ([runbooks/digest.md](runbooks/digest.md)).

| Идея | Состояние | Что мешает или что нужно |
|---|---|---|
| Сканер документов (Paperless-ngx), OCR, чеки и гарантии по фото, поиск по смыслу | **не сделано** | Paperless-ngx требует Python/Docker; OCR — Tesseract (отдельная установка) и распознавание чеков; поиск по смыслу — модель эмбеддингов. Можно сделать позже своим кодом: загрузка скана → Tesseract → текст в поиск |

## 2. Исследовательский список локальных интеграций

Ограничения проекта: **без Docker, без WSL2, без Python**; один ПК (i5-6400, 4 ядра, 16 ГБ ОЗУ, GTX 960 с 2 ГБ); никаких обращений к чужим облакам с семейными данными; никаких открытых портов и Funnel; работа только через Tailscale (и по желанию защищённый туннель); не менять DNS и ACL Tailscale. Колонка «Подходит?» — по этим ограничениям и по заявленным способам запуска.

## 3. Принципы выбора

- Сначала — то, что уже есть в системе (Jellyfin с `ffmpeg`, Windows, Chrome), потом — новый компонент.
- Каждый компонент — отдельная папка вне Git, закреплённые версия, размер и SHA-256, понятный откат и описание в runbook (так сделаны aria2 и llama.cpp: `scripts\components.json`, [local-ai.md](runbooks/local-ai.md)).
- Данные семьи не покидают дом без вашего прямого решения; никаких платных подписок на их стороне без вашего «да».
- Любая новая служба слушает только `127.0.0.1`; наружу — только через портал (который за Tailscale).
